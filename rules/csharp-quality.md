# C# Quality

Traps, not tutorials. Every line names a mistake generated C# makes by default.
The language, the BCL and ASP.NET are already in the model, and a codebase's
architecture is discoverable by reading it, so neither is in this file.

**Before trusting any rule below, assert the SDK (CS-BUILD-21) and read the effective
property back with `-getProperty:` (DN-RULE-09).** This rule installs with
`paths: ["**/*.cs", "**/*.csx", "**/*.cake"]` and loads on every C# source, script and Cake edit and on nothing else. It ships
beside `dotnet-build` in the `dotnet-essentials` bundle, and that rule owns the
project, props, `global.json`, `nuget.config`, analyzer-config, `BannedSymbols` and
`PublicAPI` files, the package build and the CI and script globs (`*.bat`, `azure-pipelines*.yml`, `appveyor.yml`, `.azuredevops/**`, `.github/actions/**/*.y*ml`), defined only in its `paths`. Binds to SDK 10.0.401, `net8.0;net10.0` and
LangVersion 14, measured 2026-10-11 on Linux x64. Windows rows were measured on SDK
10.0.102. macOS and arm64 rows are `unverified: read only`. `ocx`, `Ocx.Sdk`, `OcxClient` and
`OCX_SDK_EXE` are example names from the reference consumer; rename them. "The wrapped tool" is the CLI the library launches.

## Conventions

Every cell and the gate read these; set them once per repository and never leave a `<placeholder>` in a command. Put `TMPDIR` on the repository's disk: the gate writes 0.2-3.5 GB (bicep 2.9, refit 3.3+).

- **Operands.** Every cell runs from the repository root, `cd "$(git rev-parse --show-toplevel)"` (the Gate runs from the build root, the directory that holds `SLN`), on repo-relative paths. `SRC` and `TESTS` are space-separated lists of repo-relative directories (no space in a name) of the shipped and of the test or other non-shipped projects (Scan scope derives both); an absolute entry prints `MISSING repo-relative SRC` and stops. `SLN` is the one solution or project file the gate builds (a repository with several solutions, or none, names the one it ships), `PRJ` one shipped project file, `PACK` the packable project file (never the solution), `CIF` the existing CI definition paths, repo-relative from the root: `CIF=$(ls -d .github/workflows .github/actions azure-pipelines*.yml appveyor.yml .azuredevops 2> /dev/null | tr '\n' ' ')` (run from `src/`, a relative `CIF` finds nothing and says nothing), `REL` the tag-triggered release workflow file, `TOOL` the wrapped tool's file name, `CAN` the canary project file, `G` the `global.json` found walking up from the build root (the gate sets it) and `BASE=$(git symbolic-ref -q --short refs/remotes/origin/HEAD || echo "origin/${GITHUB_BASE_REF:-${DEFAULT_BRANCH:?MISSING BASE}}")` the merge target, never a hard-coded `origin/main` (an `actions/checkout` clone has no `origin/HEAD`; elsewhere `git remote set-head origin -a` creates it). A cell names each operand it reads as `${X:?MISSING X}` (`${SRC:?MISSING SRC}`): no default, no `for d in $SRC` loop (vacuous when unset), and a grep or `rg` exit 2 is never a pass.
- **Scan scope.** A scan of shipped code leaves out test and other non-shipped projects, found by what a project is and never by a name list: a test project sets `IsTestProject` true or references `Microsoft.NET.Test.Sdk` or a Microsoft.Testing.Platform, xunit.v3 or MSTest package, and a non-shipped one sets `IsPackable` false (a sample, a benchmark, a tool; a source generator packed into another project goes back into `SRC`). Derive both once unless set: `: "${TESTS=$({ git grep -lE 'IsTestProject>[[:space:]]*true|Microsoft\.NET\.Test\.Sdk|Microsoft\.Testing\.Platform|xunit\.v3|MSTest|TestingPlatformDotnetTestSupport|IsPackable>[[:space:]]*false' -- '*.csproj'; git grep -l 'IsTestProject>[[:space:]]*true' -- '*.props' '*.targets'; } | xargs -r -n1 dirname | sort -u | tr '\n' ' ')}"` and `: "${SRC=$(git ls-files '*.csproj' | xargs -r -n1 dirname | sort -u | grep -vxF -f <(printf '%s\n' $TESTS) | tr '\n' ' ')}"` (Ocelot `unit/` and `acceptance/` leave and its packed `testing/` stays; a shipped `Foo.Testing` package and `Latest/` stay; a `SRC` that ships nothing, such as docs samples under a root `IsPackable` false, is named by hand). The one exclusion array, which no family retypes: `X=(':(exclude,glob)**/[Tt]est/**' ':(exclude,glob)**/[Tt]ests/**' ':(exclude,glob)**/*Test/**' ':(exclude,glob)**/*Tests/**' ':(exclude,glob)**/*TestFixtures/**' ':(exclude,glob)**/*TestServices/**'); for t in $TESTS; do X+=(":(exclude)$t"); done` (the segment names back up a test directory the derivation missed), passed as `-- $SRC "${X[@]}"` to git and as `RX=(); for e in "${X[@]}"; do RX+=(-g "!${e#:(exclude*)}"); done` to rg. Every family's first cell prints `MISSING scanned zero files` when `git ls-files --cached --others --exclude-standard -- $SRC "${X[@]}" | grep -q '\.cs$'` fails. Vendored trees (`eng/common`, `submodules`, `third_party`, `ThirdParty`, `vendor`) and snapshot output (`*.verified.*`, `*.received.*`, `_snapshots/`) are skipped: CS-LANG-23, CS-TEST-13, `weaken-check.sh` and the CS-XP cells all treat them as tool output.
- **Cells.** Run each cell in `bash` 4+ (`mapfile`, array `+=`; macOS ships 3.2, and zsh aborts on `$VAR[` in a pattern, so write `${VAR}`) with `L=${L:-$(mktemp -d)}` set once and every log written as `"$L/<name>.log"`, never into the work tree (the Gate's `L`; remove an `L` you created). A cell for a tagged row opens with a probe that prints `N/A: <reason>` on stdout and exits 0 when its tag does not hold, and every `MISSING ...` line goes to stdout too, so an empty stdout is a pass only where the row applies.
- **Tags.** A rule line that does not bind everywhere leads with a tag: `[always]` (no tag means this), `[stj]` JSON is bound with System.Text.Json, `[cli-wrapper]` the library's purpose is wrapping one tool, `[launches-process]` it starts a child process at all (binds only CS-PROC-01, 09, 11, 12 and 14), `[json-cli]` the wrapped tool speaks JSON (binds CS-PROC-07, CS-PROC-19 to 22 and the CS-BIN-26 pin sentences), `[downloads-binary]` it downloads and installs a native binary, `[library]` the project is consumed as a package or API (the other kind is an `[app]`: an executable, service or tool nobody references), `[packable-library]` it ships a NuGet package, `[zero-dependency]` the owner budget that the package depends on nothing but `System.Text.Json` (CS-SEC-09), `[mtp]` every test project runs Microsoft.Testing.Platform natively, `[gha]` CI is GitHub Actions, `[greenfield]` every shipped TFM is net8.0 or newer. Outside its tag a line does not apply: state that in one line and do not satisfy it by rewriting the repository.
- **Legacy TFM.** A row that needs an API the project's lowest TFM lacks (netstandard2.0 has no `ArgumentList`, `Kill(true)`, `WaitForExitAsync`, `SetUnixFileMode` or `DiagnosticId`) binds `[greenfield]` only, and the row names the fallback.
- **Nullable.** `Nullable=enable` once in the root props and no `#nullable` directive in a new or hand-written file. A whole-file `#nullable disable` is migration debt, allowed only in a file listed with a reason in the one tracked debt file of CS-LANG-01 (a bare comment is not the record; the count only falls). The public-API pair `#nullable disable annotations` ... `restore` is sanctioned when its first line carries a same-line `//` reason, and CS-LANG-01 owns the test forms (`Nullable` set to `annotations` in a test project, one member bracketed in a test file).
- **Test runner.** `global.json` sets `test.runner` to `Microsoft.Testing.Platform` only once every test project is MTP (CS-BUILD-20). A project with `TestingPlatformDotnetTestSupport` under a VSTest `global.json` runs in bridge mode: it prints `Passed!` lines and counts as VSTest. A VSTest repository runs `dotnet test -c Release --no-build` without `--minimum-expected-tests`, and its proof is one `Passed! - ... Total: N` line per project per TFM with N above 0. A repository that mixes MTP and VSTest projects under the MTP `global.json` makes `dotnet test` exit 1 with a refusal: run `--project` per MTP test project (DN-RULE-07, CS-BUILD-20).
- **Sanctioned forms.** Each is the one stated exception to the row that names it, and a second occurrence needs the same comment: a `Regex` with `RegexOptions.NonBacktracking` carries no match timeout (CS-SEC-03, CS-PERF-03); a protocol-public digest string (an OCI `sha256:` reference) may be compared with ordinal `string.Equals` (CS-BIN-07, CS-SEC-08); a Win32 P/Invoke in a platform project and a job object for parent-death (CS-PROC-14, CS-SEC-05); `--ignore-exit-code 8` on a filter fan-out whose solution-level run keeps the count, with a comment (CS-TEST-11, DN-RULE-07); `continue-on-error: true` on a manually dispatched regenerate-and-commit job, or on a step whose `outcome` a later step of the same job gates on and fails (CS-CORE-01); `NoWarn` of IL2xxx and IL3xxx in a test project that sets `JsonSerializerIsReflectionEnabledByDefault`, and one single-statement `#pragma warning disable IL2026` pair around a call whose serialization is source-generated, the comment naming the generated context (DN-RULE-04, CS-TEST-12); the `_AssemblyInfo.cs` template output as a `generated_code` section (`analyzers.editorconfig`); in a non-shipped sample or tool project (`IsPackable` false, outside `SRC`), `NoWarn` of IL2xxx and IL3xxx and `SuppressTrimAnalysisWarnings`, `EnableTrimAnalyzer` or `EnableAotAnalyzer` set false under a comment that names the reflection the library still uses (DN-RULE-04); `NoWarn` NU1701 on one `PackageReference` with a comment, never project-wide (DN-RULE-04); a file on the reasoned allowlist of synchronous entries the library does not own (CS-ASYNC-14); a code-scoped `-warnaserror:<code>` that tightens one code on top of the props (CS-BUILD-13 owns it).

## The Gate

Run it in a fresh `bash` after every change, from the build root (the directory that holds `SLN`; `global.json` is found
walking up from it), cheapest step first, and stop at the first non-zero exit with the failed assumption or the first errors
(never warnings) printed once each in log order. CS-BUILD-16 owns the block. `PACK` binds `[packable-library]` `[greenfield]`
repositories only; unset, the pack step is skipped. The restore goes into an empty packages folder (CS-BUILD-27), removed on exit,
and a plain restore then points `obj/` back at the default folder: a `--no-restore` or `--no-build` command must follow a normal
restore (DN-RULE-05). The logs stay after a failure. Format covers the `.cs` files changed or added since `BASE`, untracked ones included; `[greenfield]` may drop
the `--include` to gate the whole tree, and a legacy tree is red on day one without it (Guard: 975 WHITESPACE). The two scripts in `.claude/rules/csharp-quality/checks/` are not in
the chain and run from the repository root: `weaken-check.sh` prints lines for a reviewer (CS-CORE-01),
and `check-ci-matrix.sh <workflows-dir>` serves CS-CI-07 (prefix `CONTRACT_VAR=<the SDK's contract
variable>` to arm R10). It needs bash 4+, git, jq, GNU `timeout` (`gtimeout` on macOS, put on `PATH` as `timeout`) and, for the budget, unzip and xmllint; the Gate checks bash, git, jq and `timeout` before anything else.

```sh
for t in git jq timeout; do command -v "$t" > /dev/null || { echo "gate: $t is not installed"; exit 1; }; done; [ "${BASH_VERSINFO:-0}" -ge 4 ] || { echo "gate: bash 4+ needed"; exit 1; }; P0=${NUGET_PACKAGES:-}; export MSBUILDTERMINALLOGGER=off DOTNET_NOLOGO=1 NUGET_PACKAGES="$(mktemp -d)"    # DN-RULE-02, CS-BUILD-27: 0.2-3.5 GB per run in $TMPDIR (default /tmp), removed on exit
L="$(mktemp -d)"; trap 'c=$?; rm -rf "$NUGET_PACKAGES"; export NUGET_PACKAGES=$P0; [ -e "${SLN:-}" ] && timeout 900 dotnet restore "$SLN" --tl:off --interactive false --disable-build-servers > "$L/rerestore.log" 2>&1; [ $c = 0 ] && rm -rf "$L"' EXIT    # the logs stay after a failure; the plain restore points obj/ back at the default packages folder (DN-RULE-05)
g() { n=$1; shift; timeout 900 "$@" > "$L/$n.log" 2>&1 || { c=$?; m=$(grep -nE '(^|[[:space:]])error( [A-Za-z0-9]+)? ?:|Zero tests ran|You must install|No test projects were found|^[[:space:]]*([Ff]ailed[ !]|failed )|Test Run Aborted|Could not find .* host|Testhost process.*exited with error|supported on Windows only|Unsupported repository version|invalid digest|invalid extension|All projects must use that test runner|VSTest target is no longer supported' "$L/$n.log" | awk '{k = $0; sub(/^[0-9]+:/, "", k)} !s[k]++' | head -20); echo "${m:-$(tail -n 5 "$L/$n.log")}"; echo "gate: $n exit $c, log $L/$n.log"; return "$c"; }; }    # DN-RULE-01, DN-RULE-03: errors only, in log order, once each, else the last 5 lines; 124 = timeout
up() { d=$(cd "$1" && pwd); until [ -f "$d/global.json" ] || [ "$d" = / ]; do d=$(dirname "$d"); done; echo "$d/global.json"; }; G=$(up .); V=$(jq -r '.sdk.version // empty' "$G" | cut -d. -f1,2)
{ test -e "${SLN:?MISSING SLN}" || ! echo "gate: SLN $SLN is not under $PWD, run from its directory"; } \
  && { test "$G" = "$(up "$(dirname "$SLN")")" || ! echo "gate: $SLN sees $(up "$(dirname "$SLN")"), not $G: run from its directory"; } \
  && { test -n "$V" || ! echo "gate: no sdk.version in $G: report the missing pin (CS-BUILD-20), do not add one, run the steps below by hand"; } \
  && g sdk dotnet --version && { grep -qE "^${V//./\\.}\.[0-9]+" "$L/sdk.log" || ! echo "gate: sdk $(head -1 "$L/sdk.log") is not $V ($G)"; } \
  && g restore dotnet restore "$SLN" --tl:off --interactive false --disable-build-servers \
  && g build dotnet build "$SLN" -c Release --no-restore --no-incremental --tl:off --interactive false --disable-build-servers \
  && { : "${BASE:?MISSING BASE}"; mapfile -t F < <({ git diff --relative --name-only --diff-filter=d --merge-base "$BASE" -- '*.cs'; git ls-files --others --exclude-standard -- '*.cs'; } | sort -u); [ ${#F[@]} = 0 ] || g format dotnet format "$SLN" --verify-no-changes --no-restore --include "${F[@]}"; } \
  && { T=(--solution "$SLN"); case "$SLN" in *.sln | *.slnx | *.slnf) ;; *) T=(--project "$SLN") ;; esac; } \
  && if jq -e '.test.runner == "Microsoft.Testing.Platform"' "$G" > /dev/null; then g test dotnet test "${T[@]}" -c Release --no-build --minimum-expected-tests 1 || { r=1; grep -q 'All projects must use that test runner' "$L/test.log" && for p in $(git grep -lE 'UseMicrosoftTestingPlatformRunner|TestingPlatformDotnetTestSupport|xunit\.v3|MSTest\.Sdk' -- '*.csproj'); do g "test-${p##*/}" dotnet test --project "$p" -c Release --no-build --minimum-expected-tests 1 || { r=$?; break; }; r=0; done; [ $r = 0 ]; }; else g test dotnet test "$SLN" -c Release --no-build && { awk '/^Passed! /{n++} /^Passed! /&&!/Total: +[1-9]/{b=1} END{exit !n||b}' "$L/test.log" || ! echo "gate: VSTest ran no test (CS-CORE-03)"; }; fi \
  && if [ -z "${PACK:-}" ]; then echo 'gate: PACK unset, pack skipped (it binds [packable-library] [greenfield])'; else rm -rf artifacts && g pack dotnet pack "$PACK" -c Release --no-build -o artifacts --tl:off --interactive false; fi
```

`[packable-library]` `[zero-dependency]` repositories run the budget next, in the same shell (CS-SEC-09):

```sh
: "${PACK:?MISSING PACK}"; N=$(timeout 120 dotnet msbuild "$PACK" -nologo -getProperty:TargetFrameworks -getProperty:TargetFramework | jq -r '.Properties | (.TargetFrameworks + ";" + .TargetFramework) | split(";") | map(select(test("^net[0-9]+\\.[0-9]+"))) | sort_by(capture("^net(?<a>[0-9]+)\\.(?<b>[0-9]+)") | [(.a | tonumber), (.b | tonumber)]) | last'); x() { unzip -p artifacts/*.nupkg '*.nuspec' | xmllint --xpath "$1" -; }
test "$(x "count(//*[local-name()='group'][@targetFramework='$N'])")" = 1 && test "$(x "count(//*[local-name()='group'][@targetFramework='$N']/*[local-name()='dependency'])")" = 0 && test "$(x "count(//*[local-name()='group']/*[local-name()='dependency'][@id!='System.Text.Json'])")" = 0 || { echo "budget: the $N nuspec group is missing or not empty, or a group lists a dependency other than System.Text.Json (CS-SEC-09)"; false; }
```

Gate on each step's exit status and never on its stdout. A task is done when a command,
its exit code and the tree it ran against are all named (CS-CORE-03). The steps are the SDK
assert (CS-BUILD-21), restore, build (CS-BUILD-13), format (CS-BUILD-16), test (CS-TEST-06)
and pack with package validation (CS-PKG-09). A repository with no `sdk.version` pin gets the missing pin reported and never
added, and one on another SDK keeps its own pin (refit pins SDK 11). A failure line that the `dotnet-diagnose` catalogue's host-condition row lists is a
host condition: report it and stop (DN-RULE-06).

## Non-Negotiables

Every line blocks a merge within the scope it names; a tagged line binds only where its tag holds
(Conventions). IDs resolve through [Where the Depth Is](#where-the-depth-is). CS-BUILD and CS-PKG live in `dotnet-build`.

- Never reach green by weakening a check without a written reason per weakened item, and never trust a check nobody watched go red; the sanctioned forms are in Conventions (DN-RULE-04 owns the three `NoWarn` exceptions and the non-shipped sample's analyzer switches). CS-CORE-01, CS-CORE-02
- [library] Warnings are errors from the props, unconditionally: only NU1900-NU1905 are exempt, and never a bare `-warnaserror` or `-p:TreatWarningsAsErrors=false` (a code-scoped `-warnaserror:<code>` tightening is CS-BUILD-13's); an `[app]` in migration may carry a selective `WarningsAsErrors` list while a comment names the migration. CS-BUILD-13
- Run every `dotnet` command under `timeout`, output redirected to a file under `$L`, and read the file; a `.ps1`, `.cmd` or `.bat` has no `timeout` and is bounded by its workflow step's `timeout-minutes`. DN-RULE-01
- [mtp] "Tests green" means tests ran: read the MTP exit by number, gate on `--minimum-expected-tests`, never ignore 8 (one filter fan-out excepted, Conventions); under VSTest or bridge mode one `Passed!` line with Total above 0 per project and TFM. DN-RULE-07, CS-CORE-03
- Set `Nullable` once in the root props and write no `#nullable` directive in a new file; a legacy file keeps `#nullable disable` only while it is listed with a reason, and CS-LANG-01 owns the test-project and test-file forms (Conventions). CS-LANG-01
- The null-forgiving operator takes three forms only: `= null!;` on a `[JsonRequired]` member, a `!` with a same-line invariant comment, and a reflection or API-contract `!` inside one internal `Reflect.New<T>` / `Invoke<T>` helper that states the invariant once; Roslyn symbol APIs in an analyzer or generator project are exempt. CS-LANG-03
- Validate every dereferenced reference parameter of a public member on its first lines with the throw helpers. CS-LANG-05
- No hand-written file carries a generated-code marker, and nothing under `obj/` is committed. CS-LANG-23
- Every public async method that does I/O ends with `CancellationToken cancellationToken = default`, the token last. CS-ASYNC-01
- No `.Result`, `.Wait()`, `GetAwaiter().GetResult()`, `Task.WaitAll` or `Thread.Sleep` in library code, except a file on CS-ASYNC-14's reasoned allowlist of synchronous entries. CS-ASYNC-14
- No `async void` and no async lambda converted to a void delegate, callback options included. CS-ASYNC-16
- No fire-and-forget: store background tasks and await them on every exit path. CS-ASYNC-17
- [launches-process] Build argv only with `ProcessStartInfo.ArgumentList`, never `Arguments`. CS-PROC-01
- [cli-wrapper] `FileName` is only the absolute path the one resolver produced, in the one order. CS-PROC-03
- [cli-wrapper] Pass secrets only as stdin bytes or child environment variables, never in `ArgumentList`, logs or exceptions. CS-PROC-08
- [launches-process] Drain stdout and stderr with one byte-pump task each, and kill with `Kill(entireProcessTree: true)` then a bounded reap. CS-PROC-09, CS-PROC-14
- [greenfield] Never call `Path.Combine`: join your own literals with `Path.Join` and every foreign segment through one `PathSafe.Combine`. CS-XP-01
- Data that crosses a process or file boundary is culture-free: `InvariantCulture` for numbers and dates, ordinal comparisons for keys. CS-XP-07
- [library] [greenfield] Every clock, delay and timeout in `src` takes the injected `TimeProvider`. CS-XP-11
- [stj] Bind JSON only through a source-generated `JsonTypeInfo`: no reflection overload, no explicit-generic `Deserialize<T>()`; a serializer adapter whose type comes from the caller may keep the reflection overload beside a `JsonTypeInfo` path (refit `SystemTextJsonContentSerializer`). CS-JSON-01
- Write every success predicate as an allow-list of success values, never `!= Failed`. CS-JSON-06
- `catch (Exception)` and bare `catch` are allowed at three sites only. CS-ERR-06
- Give every `Regex` a match timeout of at most 1 s, and a literal pattern a `[GeneratedRegex]`. CS-SEC-03
- [cli-wrapper] The fake-CLI tests pin the engine's process behaviour on every PR leg. CS-TEST-04

## Rules This File Owns

The CS-CORE and DN-RULE families are defined here and nowhere else. Every other family
is defined in a depth file or in `dotnet-build` and only cited here. `src/Lib` is an
example project path: rename it. DN-RULE binds every `dotnet` invocation, and the
procedure skills load it.

## Owner Defaults
