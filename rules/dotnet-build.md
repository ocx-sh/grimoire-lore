# .NET Build

Traps, not tutorials. Every line names a mistake an agent makes by default in a project file, a props file, a `global.json`,
a `nuget.config`, an analyzer config or a CI build step. MSBuild and NuGet semantics are already in the model.

Contents: [Gate](#the-gate) · [Non-Negotiables](#non-negotiables) · [Rules](#rules-this-file-owns) · [Posture Files](#posture-files) ·
[Depth](#where-the-depth-is) · [Severity](#severity)

Installed with the 22 globs in the frontmatter, the one definition of this group: project, props, targets, `.proj` and solution files, `global.json`, `nuget.config` in
all three spellings, `.globalconfig` and `*.globalconfig`, `BannedSymbols*.txt`, every `PublicAPI*.txt` (also the per-TFM `PublicAPI/<tfm>/` folders),
`packages.lock.json`, `dotnet-tools.json`, a workflow or composite action (`.github/**/*.y*ml`), and a `*.ps1`, `*.sh`, `*.cmd` or `[Bb]uild.*` script (`build.cake`, `build.bat`; a `dotnet-releaser.toml` is read through its workflow) (so a workflow or build-script edit meets DN-RULE-01 and CS-BUILD-30
here; the source-level rows are in `csharp-quality`). `.editorconfig` is not globbed (not .NET specific; a `*.cs` edit loads
`csharp-quality`, whose CS-CORE-01 routes it here). A `Dockerfile`, a `*.fsproj`, a `*.ruleset` and a `*.nuspec` never load this file. It ships beside `csharp-quality` in the `dotnet-essentials` bundle. Binds to .NET SDK 10.0.401 on Linux x64
(measured 2026-10-11), runtimes 10.0.12 and 8.0.31, SDK 8.0.425 for the floor leg and SDK 11.0.100-rc.1.26425.128 for probes
only. Windows, macOS and arm64 rows are `unverified: read only`. .NET 8 and 9 end support on 2026-11-10.

**Read the effective value after every pin edit: an invalid `global.json`, a typo'd `AnalysisLevel` or a bulk severity line is
ignored with exit 0, and the build then runs on whatever the machine has.** CS-BUILD-10, CS-BUILD-20 and CS-BUILD-21 give the read-back.

## The Gate

Run it in a fresh `bash` from the build root (the directory holding `SLN`, set per `csharp-quality` Conventions; `global.json` is
found walking up from it), cheapest step first; it stops at the first non-zero exit and prints the failed assumption or that
step's first errors, once each in log order (DN-RULE-01 wraps every `dotnet` call, DN-RULE-02 puts the knobs in the environment). CS-BUILD-16 owns it, and
`csharp-quality` quotes it verbatim. The restore folder is removed on exit (0.2-3.5 GB under `$TMPDIR`; put `TMPDIR` on the repository's disk) and a plain restore then
points `obj/` back at the default folder, so a `--no-restore` or `--no-build` command must follow a normal restore (DN-RULE-05); the logs stay after a
failure. `PACK` binds `[packable-library]` `[greenfield]` repositories and is the project file, never the `.slnx` (CS-BUILD-29); unset, the pack step is skipped. Format covers the `.cs` files
changed since `BASE` (`[greenfield]` may drop the `--include`; a legacy tree is red on day one without it). A missing `sdk.version` pin is reported, never added. A task is done when its command, exit code and tree are
named. It needs bash, jq, unzip, xmllint and GNU `timeout` (`gtimeout` on macOS).

```sh
P0=${NUGET_PACKAGES:-}; export MSBUILDTERMINALLOGGER=off DOTNET_NOLOGO=1 NUGET_PACKAGES="$(mktemp -d)"    # DN-RULE-02, CS-BUILD-27: 0.2-3.5 GB per run in $TMPDIR (default /tmp), removed on exit
L="$(mktemp -d)"; trap 'c=$?; rm -rf "$NUGET_PACKAGES"; export NUGET_PACKAGES=$P0; [ -e "${SLN:-}" ] && timeout 900 dotnet restore "$SLN" --tl:off --interactive false --disable-build-servers > "$L/rerestore.log" 2>&1; [ $c = 0 ] && rm -rf "$L"' EXIT    # the logs stay after a failure; the plain restore points obj/ back at the default packages folder (DN-RULE-05)
g() { n=$1; shift; timeout 900 "$@" > "$L/$n.log" 2>&1 || { c=$?; grep -nE '(^|[[:space:]])error( [A-Za-z0-9]+)? ?:|Zero tests ran|You must install|No test projects were found|^[[:space:]]*failed ' "$L/$n.log" | awk '{k = $0; sub(/^[0-9]+:/, "", k)} k ~ /^[[:space:]]*(error( [A-Za-z0-9]+)? ?:[[:space:]]*)?(at [^ ]+ ?[(]|--- )/ {next} !s[k]++' | head -20; echo "gate: $n exit $c, log $L/$n.log"; return "$c"; }; }    # DN-RULE-01, DN-RULE-03: errors only, in log order, once each, stack-trace frames dropped (a task that logs stderr as errors fills 20 lines with them); 124 = timeout
up() { d=$(cd "$1" && pwd); until [ -f "$d/global.json" ] || [ "$d" = / ]; do d=$(dirname "$d"); done; echo "$d/global.json"; }; G=$(up .); V=$(jq -r '.sdk.version // empty' "$G" 2> /dev/null | cut -d. -f1,2)
{ test -e "${SLN:?MISSING SLN}" || ! echo "gate: SLN $SLN is not under $PWD, run from its directory"; } \
  && { test "$G" = "$(up "$(dirname "$SLN")")" || ! echo "gate: $SLN sees $(up "$(dirname "$SLN")"), not $G: run from its directory"; } \
  && { test -n "$V" || ! echo "gate: no sdk.version in $G: report the missing pin (CS-BUILD-20), do not add one, run the steps below by hand"; } \
  && g sdk dotnet --version && { grep -qE "^${V//./\\.}\.[0-9]+" "$L/sdk.log" || ! echo "gate: sdk $(head -1 "$L/sdk.log") is not $V ($G)"; } \
  && g restore dotnet restore "$SLN" --tl:off --interactive false --disable-build-servers \
  && g build dotnet build "$SLN" -c Release --no-restore --no-incremental --tl:off --interactive false --disable-build-servers \
  && { : "${BASE:?MISSING BASE}"; mapfile -t F < <(git diff --relative --name-only --diff-filter=d --merge-base "$BASE" -- '*.cs'); [ ${#F[@]} = 0 ] || g format dotnet format "$SLN" --verify-no-changes --no-restore --include "${F[@]}"; } \
  && if jq -e '.test.runner == "Microsoft.Testing.Platform"' "$G" > /dev/null; then g test dotnet test --solution "$SLN" -c Release --no-build --minimum-expected-tests 1; else g test dotnet test "$SLN" -c Release --no-build && { awk '/^(Passed|Failed)! /{n++} /^(Passed|Failed)! /&&!/Total: +[1-9]/{b=1} END{exit !n||b}' "$L/test.log" || ! echo "gate: VSTest ran no test (CS-CORE-03)"; }; fi \
  && if [ -z "${PACK:-}" ]; then echo 'gate: PACK unset, pack skipped (it binds [packable-library] [greenfield])'; else rm -rf artifacts && g pack dotnet pack "$PACK" -c Release --no-build -o artifacts --tl:off --interactive false; fi
```

`[packable-library]` `[zero-dependency]` repositories run the budget next, in the same shell (CS-SEC-09):

```sh
: "${PACK:?MISSING PACK}"; N=$(timeout 120 dotnet msbuild "$PACK" -nologo -getProperty:TargetFrameworks -getProperty:TargetFramework | jq -r '.Properties | (.TargetFrameworks + ";" + .TargetFramework) | split(";") | map(select(length > 0)) | sort_by((ltrimstr("net") | tonumber?) // 0) | last'); x() { unzip -p artifacts/*.nupkg '*.nuspec' | xmllint --xpath "$1" -; }
test "$(x "count(//*[local-name()='group'][@targetFramework='$N'])")" = 1 && test "$(x "count(//*[local-name()='group'][@targetFramework='$N']/*[local-name()='dependency'])")" = 0 && test "$(x "count(//*[local-name()='group']/*[local-name()='dependency'][@id!='System.Text.Json'])")" = 0 || { echo "budget: the $N nuspec group is missing or not empty, or a group lists a dependency other than System.Text.Json (CS-SEC-09)"; false; }
```

## Non-Negotiables

Every line blocks a merge within the scope it names. IDs resolve through the rules table below and the sibling files.

| # | Rule | ID |
|---|---|---|
| 1 | The TFM list lives in the root `Directory.Build.props` (or the one shared `*.targets` every shipped project imports) and nowhere else; a project may read it from a root property (the `net472` test leg: `tests/Directory.Build.props`, CS-BUILD-03). | CS-BUILD-01 |
| 2 | `LangVersion` is the literal `14`, never `latest`. | CS-BUILD-04 |
| 3 | `AnalysisLevel` is `10.0-all`, once, in the root props. | CS-BUILD-10 |
| 4 | No analyzer ID in `NoWarn`; the repo-wide `none` list is the five IDs with a reason line each. | CS-BUILD-12 |
| 5 | `[library]` `TreatWarningsAsErrors` is unconditional in the props; never a bare `-warnaserror` (a selective `-warnaserror:<ID>` is allowed); only NU1900-NU1905 are exempt (an `[app]` in migration may carry a selective `WarningsAsErrors` list under a migration comment). | CS-BUILD-13 |
| 6 | Five analyzer packs and MinVer as `GlobalPackageReference` at exact versions; never StyleCop, Roslynator or NetAnalyzers. | CS-BUILD-15 |
| 7 | A `global.json` at or above the build root with an exact three-part version, `latestFeature` (or the stricter `latestPatch`), no prereleases unless the repository targets a preview TFM and pins that exact prerelease SDK. | CS-BUILD-20 |
| 8 | Every package version lives in `Directory.Packages.props`; no `Version=` on a `PackageReference`. | CS-BUILD-23 |
| 9 | No `packages.lock.json` for a library. | CS-BUILD-25 |
| 10 | A root `nuget.config` that clears and maps every source; CI restores into an empty packages folder (a cache is allowed only keyed on the lock hash under a locked restore). | CS-BUILD-27 |
| 11 | `[packable-library]` `[zero-dependency]` The packed nuspec carries the dependency budget: the newest TFM group empty, every other group `System.Text.Json` only. | CS-SEC-09 |
| 12 | `[packable-library]` `[gha]` Publish to nuget.org only through Trusted Publishing; no `NUGET_API_KEY` secret exists. | CS-PKG-11 |

## Rules This File Owns

The CS-BUILD family is defined here and nowhere else; the CS-PKG rows are in [dotnet-build/packaging.md](dotnet-build/packaging.md).
CS-BUILD-07 is retired (binary selection moved to CS-XP-10's bans), 09 and 19 were never assigned.
**Scope.** CS-BUILD-02, 03, 06, 08, 29 and every CS-PKG row bind `[packable-library]` repositories (tags: `csharp-quality`
Conventions). A tool, benchmark, sample or test project in the same repository is outside them; an analyzer, source-generator or
MSBuild-task project targets `netstandard2.0` and is not packed as a library; a build tool that owns versioning (Nuke, Arcade,
`version.json`) replaces MinVer when the repository says so in one line. A grep, awk or find check prints its violation, so empty
output is the pass (grep exits 1 on no match, 123 behind `xargs`: ignore it). Run every cell from the repository root, the one cwd (`git rev-parse --show-toplevel`), with the operands it names set (Conventions: `SRC`, `SLN`, `PRJ`, `PACK`, `BASE`, `G`, `CIF`, which also lists `.github/actions`):
the first lines of the cell block define `top`, which finds the shallowest file of a name, so a root props below the repository root (bicep, markdig: `src/`) needs no `cd`; an unset operand fails with `MISSING <x>`, a CI scan reads `${CIF:?MISSING CIF}` and never a relative `.github/workflows` (refit run from `src/` lost all CI), and a `No such file` line is never the pass.
Rows 04, 10, 13 and 26 read effective values through `dotnet msbuild -getProperty` once per TFM of the default list (edit the
loop) so a per-TFM `Condition` override shows. Every runnable cell was watched red on a planted defect and green on its twin
(SDK 10.0.401, `net8.0;net10.0`, 2026-10-11), except the gate's `dotnet test` line (CS-TEST-06) and cells marked `unverified`.

## Posture Files

The analyzer posture is one set of files in `.claude/rules/dotnet-build/checks/`, copied into the repository once and then
diffed, never hand-edited down: `BannedSymbols.txt` (repo-wide) and `BannedSymbols.Src.txt` (registered as `AdditionalFiles`
from the root `Directory.Build.targets`, by project: `Condition="'$(IsPackable)' != 'false' And '$(IsTestProject)' != 'true'"`, which reads the project body; a layout without `src/` and `tests/` siblings needs no edit), `analyzers.globalconfig` (installed as the root `.globalconfig`),
`analyzers.editorconfig` (appended to the root `.editorconfig`), `Directory.Packages.analyzers.props` (the packs of
CS-BUILD-15) and `posture-check.sh` (run from CI: no duplicate symbol, RS0030 and RS0031 at `error`, both ban files
registered, every shipped severity line still present). Each symbol and each severity line is defined once, in those files;
the family rows name the ID and the file and never restate the line. **Install.** Step 0 is central package management (CS-BUILD-23): 3 of 5 held-out trees carried inline `Version=`,
and the packs go into `Directory.Packages.props`, so move every version there first. Set `end_of_line` in the root `.editorconfig` (and `.gitattributes`) before IDE0055 becomes an error: a CRLF checkout against `lf` fails every file. Then copy the whole `checks/` directory and keep it together: `posture-check.sh` reads its siblings
and fails from a repository root that holds the script alone.

**Where a severity line goes.** `.globalconfig` holds every CA, RS, MA, SYSLIB, VSTHRD, IDISP, xUnit and IL severity that is
the same for `src` and tests. `.editorconfig` holds only IDE rules, editorconfig options (`generated_code` for committed generator output and vendored directories, the
collection-expression style) and path-scoped differences: the `src`-only CA2007 and MA0004 errors, CS-TEST-12's section.
A CA severity in `.editorconfig` for the whole tree, or a second `.globalconfig` for tests, is a defect (CS-BUILD-17).
