// Install at the repository root and register once from the root Directory.Build.props:
//   <AdditionalFiles Include="$(MSBuildThisFileDirectory)BannedSymbols.txt" />
// The file name must be BannedSymbols.txt or BannedSymbols.*.txt; any other name bans nothing (exit 0, measured 2026-10-11).
// A documentation ID without a parameter list bans only the parameterless overload, so every overload has its own line.
// Every symbol appears once across this file and BannedSymbols.Src.txt (a duplicate is RS0031, an error). Each message names one rule.
// A deliberate use carries `#pragma warning disable RS0030 // <reason>` on the line; never delete a line (CS-CORE-01).
// A legacy-TFM fallback (`#if NETFRAMEWORK`, `#if !NET8_0_OR_GREATER`, `#if NETSTANDARD2_0`) keeps the banned call inside the one seam of that
// `#if` branch, under `#pragma warning disable RS0030 // <reason>` ... `#pragma warning restore RS0030`; this file is the greenfield posture.
// Watched red on a canary and green on its twin, net8.0 and net10.0 (measured 2026-10-11).
