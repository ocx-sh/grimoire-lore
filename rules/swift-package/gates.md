# Gates

Binds to Swift 6.4.0 and 6.3.3 with the bundled `swift format`, SwiftLint 0.65.1, SwiftFormat 0.63.1 (incumbent only) and
swiftlang/github-workflows 0.0.15, measured 2026-10-10 on Linux x86_64 unless a row says read.

Owns the ordered done-gate, the format step and both lint configs, the escape-hatch scan, warning control, the
API-breakage, DocC and TSan jobs, the changed-files `Never*` gate and CI hygiene. Manifest content, tools floors, the lock
policy and the `.spi.yml` glob are `SW-PKG`. The weaken list, plant-and-twin and the canary are `SW-CORE-01` to
`SW-CORE-03`, generated files `SW-CORE-06`, release jobs and image pins `SW-REL`. Neighbours: `Never*` intent `SW-ERR-05`,
test sleeps `SW-TEST-03`, `exit(` `SW-CLI-03`, coverage `SW-TEST-16`, the sanitizer test recipe `SW-TEST-17`, scan policy
`SW-CONC`. **SDK** means the pinned default shape, a published library wrapping a command-line tool, otherwise read library.

## Dates, Defaults and Exit Codes

Each "watched red" is a planted violation and a compliant twin (measured 2026-10-10). Windows, macOS and Xcode legs are
`unverified: read only`. `$CHECKS` is the swift-quality rule's own `checks/` directory (`k07.sh`, `never-gate.sh`,
`swiftlint-gate.sh`, `tsan-check.sh`), pinned in the done-gate block to its installed path. A grep check's
output is the violation and empty output is the pass, never grep's exit status (1 on no match, 123 behind `xargs`), and a
presence check says otherwise in its cell. Every grep over `.` carries `--exclude-dir='.build' --exclude-dir='.claude' --exclude-dir='.agents'`, because an installed rule file quotes the patterns and would match itself, and a grep over Swift sources is `-R` (`-r` skips symlinks). `$BASE` is the merge target (`origin/main` in CI).

| Command | Exit code |
|---|---|
| `swift format lint` without `--strict` | 0 on findings |
| the format triple (SW-GATE-02) | 123 on a finding behind `xargs`, 1 on a residual `git diff` |
| `swift build -Xswiftc -warnings-as-errors`, `diagnose-api-breaking-changes`, `k07.sh` | 1 on a warning, 1 on a break, 1 on any output line |
| `never-gate.sh` | 123 on a finding, 65 no rules block, 66 no config or a `BASE` that does not resolve |
| `swiftlint-gate.sh` | 2 on a violation, 70 on a skipped rule or a refused `swiftlint_version` pin, 66 on no config, 134 on an abort |
| `tsan-check.sh` | 1 on a data race or a failing test, 70 when TSan could not start (`FATAL: ThreadSanitizer`, `ThreadSanitizer: CHECK failed`), the build failed, no passing run line was found or `TSAN_TIMEOUT` seconds (default 1200) expired (the stderr line says `outran`), 69 when GNU `timeout` is missing |
| `swift test --sanitize=thread` | 1 on a race (6.4.0). A TSan binary run directly exits 66 by default (read 2026-10-10) |

## The Done-Gate

Gate: the block below, in order, stopping at the first non-zero exit. Steps 4 and 5 bind libraries and the SDK.

```sh
# done-gate: repository root, pinned toolchain
CHECKS=.claude/rules/swift-quality/checks    # pinned default: where the swift-quality rule's checks/ directory is installed
git add -A -- '*.swift' \
  && git ls-files -z --cached --others --exclude-standard -- '*.swift' | xargs -r -0 swift format format --parallel --in-place \
  && git ls-files -z --cached --others --exclude-standard -- '*.swift' | xargs -r -0 swift format lint --strict --parallel \
  && git diff --exit-code -- '*.swift'    # 1 SW-GATE-02. 123 = a finding behind xargs. A clean CI checkout omits the git add line
BASE=origin/main bash "$CHECKS/never-gate.sh"    # 1b SW-GATE-28. Adopted repositories whose config keeps Never* off. Skip it in a new repository (exit 66 without BASE)
BASE=origin/main bash "$CHECKS/k07.sh"           # 1c SW-GATE-10. Any output line is a violation. A new repository drops BASE= (whole tree)
swift build -Xswiftc -warnings-as-errors      # 2 SW-GATE-13. Add --force-resolved-versions to 2 and 3 when Package.resolved is tracked (SW-GATE-03). A .v5 package without StrictConcurrency adds mode5-warnings, whose warning lines are the finding
env SWIFT_TESTING_XCTEST_INTEROP_MODE=complete swift test -Xswiftc -warnings-as-errors    # 3 SW-TEST-10 pin for 6.4+ legs at tools below 6.4. A .v5 package also counts warning lines here (mode5-warnings, SW-GATE-13)
swift package diagnose-api-breaking-changes "$BASELINE"    # 4 SW-GATE-20
if DOCC=1 swift package plugin --list | grep -q generate-documentation; then DOCC=1 swift package plugin generate-documentation --target "$DOCC_TARGET" --warnings-as-errors --analyze; else echo 'SKIP 5: no docc plugin declared'; fi    # 5 SW-GATE-21. A SKIP is not a pass, it is a missing dependency. The DOCC=1 before --list matters: the plugin is declared only under that variable
```
