# Unsafe APIs and Supply Chain

Binds to SDK 10.0.401 on Linux x64, TFMs `net8.0` and `net10.0`, `Microsoft.CodeAnalysis.BannedApiAnalyzers` 5.6.0, MinVer 8.0.0 and
`System.Text.Json` 10.0.12 (the net8.0 asset), measured 2026-10-11 unless a row says read. Windows and macOS rows are `unverified: read only`.

Owns what a library does with data it did not write and with packages it did not write: which analyzers fire, which bans close the silent gaps,
and what the nupkg is allowed to depend on. Not owned here: binary acquisition, the pin, the TLS validation lines and `ReadAs*` are `CS-BIN`
(`CS-BIN-16`); the environment scrub and secret handling are `CS-PROC` (`CS-PROC-06`, `CS-PROC-08`); JSON unions are `CS-JSON-07` and `CS-API-08`;
generated regex is `CS-PERF-03`; the global severity list is `CS-BUILD-12`; the weaken list is `CS-CORE-01`; the nuspec clause of the pack gate
is `CS-BUILD-24` and cites `CS-SEC-09`. `BinaryFormatter` and its siblings, XXE by default, entity bombs, weak hash and cipher constructors, the
SQL and XML-reader analyzers and the `Rfc2898DeriveBytes` constructors need no row: `SYSLIB0011` is a compile error from net7, the runtime throws
on net8, and net9 and later keep an always-throwing stub, `XmlReader.Create` throws on a DOCTYPE with a null resolver by default, the entity cap is 1e7
characters, and CA5350, CA5351, CA5379 and `SYSLIB0060` fire at `10.0-all`.

## Dates and Defaults

- The pinned install path of the posture files is `.claude/rules/dotnet-build/checks/`: `BannedSymbols.txt` (its security section is the ban set below),
  `analyzers.globalconfig` and `posture-check.sh`. Rows cite them by that path. `eng/build-code-packages.txt`, `eng/licenses.sh`,
  `eng/license-exceptions.txt`, `eng/runtime-dependencies.txt`, `eng/native-imports.txt` and `eng/integration-surface.txt` are adopter files named as example paths.
- Defaults the adopter may override once: the 1 s regex timeout, the packed budget (`CS-SEC-09`), the licence allow-list (`CS-SEC-13`), the cooldown
  of 3 days (Dependabot `cooldown` or Renovate `minimumReleaseAge`), `signatureValidationMode` left at `accept` and no SBOM in the nupkg (`CS-SEC-14`, `CS-SEC-15`, `CS-SEC-16`).
- Every command runs from the repository root. `rg` commands print violations and empty output passes; a line that says otherwise is explicit.
  Tools: `rg`, `jq`, `xmllint`, `unzip`, `curl`, `awk`, `sed`, plus the .NET SDK. The layout is a variable, not an assumption: `SRC` and `TESTS` are
  space-separated directory lists, `PRJ` the packable project and `PACK` the directory `dotnet pack -o` wrote, none with a default (a block starts
  `: "${SRC:?MISSING SRC}"`), and the central package files and `nuget.config` are found wherever they sit. A missing file operand prints
  `MISSING-OPERAND <path>` (`rg` exits 2 with empty stdout, which reads as a pass); a directory in `SRC` that does not exist makes `rg` and `find` print an error, never a pass.
- Applicability tags open a Rule cell; an untagged row is `[always]`. `[consumer]` reads a wire format through a parser or serializer it does not
  implement. `[packable-library]` ships a nupkg. `[wrapper]` acquires and verifies a binary. A library that implements the serializer or the XML
  parser is not a `[consumer]`.
- .NET 8 and 9 reach end of support on 2026-11-10. `net10.0`-only is the end state: `CS-SEC-09` then budgets zero dependencies.

## Decisions

- The gate already covers the analyzers: `AnalysisLevel=10.0-all` sets all 94 security IDs to warning and warnings-as-errors makes them errors (`CS-SEC-01`).
- Eight hazard classes stay silent under the gate. One security section of the ban file closes seven of them (`CS-SEC-01` and `CS-SEC-07` close `Random`), with `RS0030` and `RS0031` at `error`, because
  `-p:TreatWarningsAsErrors=false` turned all 24 bans into warnings and the build exited 0 (`CS-SEC-02`).
- Polymorphism: the tag-first converter of `CS-JSON-07` wins over a `[JsonDerivedType]` allow-list. Both refuse a type named by wire data; only the
  converter survives an unknown tag without throwing (`CS-SEC-04`).
- `FixedTimeEquals` applies to bytes that authenticate a download, through one helper. A digest the protocol publishes stays an ordinal string (`CS-SEC-08`).
- Retry jitter draws from `RandomNumberGenerator.GetInt32`. The only `CA5394` pragma in `src` sits in the one seeded type of a library whose product is
  seedable (`CS-SEC-07`); the only `CA5350` or `CA5351` pragma sits in the one file of a protocol that mandates a weak hash, and the only `CA5359` pragma in the one file that builds an operator-chosen accept-any callback (`CS-SEC-06`).
- The packed dependency budget is the owner file `eng/runtime-dependencies.txt`, in the reference shape `net10.0` empty and `net8.0` `System.Text.Json` only, read from the nuspec, never from `dotnet package list` (`CS-SEC-09`).
- MinVer is a `GlobalPackageReference`, not `PackageReference Version=` (NU1008 under central package management): it never reaches the nuspec (`CS-SEC-10`).
- Supply-chain controls that matter are a named build-code allow-list and an existence check on every new package ID. Signature enforcement, an SBOM and
  a `nuget verify` sweep stay off at v1 (`CS-SEC-11`, `CS-SEC-12`, `CS-SEC-15`, `CS-SEC-16`).
- Binary trust at v1 is a compiled-in, triangulated SHA-256 pin, not a signature; that family is `CS-BIN`.
- Ban fragments merge without a duplicate symbol: a duplicate raises `RS0031`, an error under warnings-as-errors (`CS-SEC-02`).

## Silent Hazards

"Silent" means no analyzer fires at `AnalysisLevel=10.0-all` with no extra configuration, on net8.0 and net10.0 (measured 2026-10-11: 25 security IDs
fire on the planted project, identical on both TFMs).

```bash
rg -n --glob '*.cs' -e "#pragma warning disable[^/]*($SEC)" -e "SuppressMessage\s*\([^)]*\"($SEC)\b" $SRC | grep -v -E "$OK"   # CS-SEC-06: the compiler ignores the SuppressMessage category, so the ID decides
for id in CA5350 CA5351 CA5394 CA5359; do test "$(rg -l --glob '*.cs' "#pragma warning disable $id" $SRC | wc -l)" -le 1 || echo "SECOND-FILE $id"; done   # CS-SEC-06: one file per sanctioned ID

test "$(rg -l --glob '*.cs' -e '\bnew\s+Random\s*\(' -e 'Random\s*\.\s*Shared' $SRC | wc -l)" -le 1 || echo "SECOND-FILE Random"   # CS-SEC-07: one seeded type
```

```bash
# eng/licenses.sh (bash): "<id>/<version> <SPDX expression or NO-SPDX-EXPRESSION>" per resolved package; the argument is a restored project file, and MSBuild names its assets file (a BaseIntermediateOutputPath override moves it out of obj/).
```
