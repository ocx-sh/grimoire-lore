# Testing and CI

Binds to .NET SDK 10.0.401 (runtimes 10.0.12 and 8.0.31) on Linux x64, `net8.0;net10.0`, `xunit.v3.mtp-v2` 4.0.2 (measured 2026-10-11).
Windows rows measured on SDK 10.0.102 say so. Every macOS and arm64 claim is `unverified: read only`.

Owns the test tiers, the fake-CLI harness, the runner and its exit codes, the test-project analyzer carve-out, test-code hygiene,
coverage, snapshots, properties and the CI matrix. Not owned here: the process engine the harness exercises is `CS-PROC` and `CS-BIN`,
path and clock guards are `CS-XP`, the analyzer posture is `CS-BUILD`, the behaviour table is `CS-ERR-12` to `CS-ERR-15`. **SDK** means
the pinned default shape, a library that wraps a command-line tool. The names `Ocx.Sdk.*` (projects), `Ocx.Fake` (the dummy tool),
`OCX_SDK_CONTRACT` (the contract-tier switch) and `TestedOcxVersion` are example names from the reference consumer; rename them once.

Applicability: an untagged row binds every repo this file loads for. `[cli-wrapper]` binds a library that wraps a command-line tool (the four tiers, the dummy tool, the contract tier, the triple and musl legs). `[greenfield]` binds a new test stack: an incumbent stack (VSTest, xUnit v2, NUnit 3, a mocking or assertion library the base branch already references) is kept and recorded in the pull request. A mandate that names an API a TFM lacks (`ExcludeFromCodeCoverage.Justification` before net5.0) binds only the TFMs that have it; elsewhere the reason is a `// justification:` comment on the line above. The CS-CI rows and `check-ci-matrix.sh` bind `[gha]` repositories (GitHub Actions); on another CI system the intent carries over and the script does not run.

- Gap: SDK 11.0.100-rc.1 fails an all-skipped whole run with exit 8, SDK 10.0.401 exits 0 (measured 2026-10-11). The per-module minimum of `CS-TEST-06` fails both.

- Gap: no GitHub runner has executed the reference workflow, the armed contract tier has not run against a real tool, and `echo-argv` (`CS-TEST-02`, `CS-TEST-29`) is a design commitment that is not built. The first CI dispatch settles all three.
- Gap: the coverage extension documents no Linux or macOS arm64 instrumentation, so arm64 and macOS legs collect nothing (`CS-TEST-19`).

## Static Checks

Run from the repository root of a git checkout. `SRC` and `TESTS` list the production and test project directories, space-separated; they may sit under `src/` side by side, so name them. `SLN` is the solution or project file `dotnet` takes (two solutions in a directory fail with MSB1011), `GJ` the `global.json`, `WF` the directory of workflow files, `BASE` the merge target from `origin/HEAD`, never assumed `main`, and `GOLD` the optional golden or baseline directories the repository declares, space-separated (empty means none; cs-test-22 finds them). An unset required operand stops the block (`${SRC:?MISSING SRC}`) and a missing path prints `MISSING OPERAND`, because a check over a missing path prints nothing and reads as a pass. `GF` is 1 when `BASE` references no test framework: a `[greenfield]` check runs only then, and in an incumbent repo it prints one `incumbent: kept` line, the record for the pull request and not a finding. `MTP` is 1 when a test project runs Microsoft.Testing.Platform (the three runner switches, `TestRunnerName` or a TUnit reference): an `[mtp]` check runs only then, and the coverage and xUnit v3 checks run only where their tool is referenced (`CT` is 1 when an MTP coverage tool is), so a repository without it prints one `skipped` line instead of a failure that holds by design.
`rg` honours `.gitignore` and skips hidden paths, so workflow files are passed as the explicit `.github` operand and dotfiles by `-g`. **Empty output is the pass** (a label that says `presence` inverts that); `\s*\(` tolerates the spaced call style `Name (args)`. A pipeline ending in `xargs -r` judges by output, never by status. Exit codes: `dotnet test` under MTP is 0 pass, 2 failed test, 5 unknown option, 8 zero tests, 9 below the per-module minimum.

```sh
CHECKS=.claude/rules/csharp-quality/checks    # pinned default: where this rule's checks/ directory is installed
# set once per repository, no defaults: SRC=src TESTS=tests WF=.github/workflows SLN=Acme.slnx GJ=global.json; GOLD optional
: "${SRC:?MISSING SRC}" "${TESTS:?MISSING TESTS}" "${WF:?MISSING WF}" "${SLN:?MISSING SLN}" "${GJ:?MISSING GJ}"; GOLD=${GOLD:-}
for d in $SRC $TESTS $WF; do [ -d "$d" ] || echo "MISSING OPERAND $d"; done
for v in SRC TESTS; do for p in ${!v}; do case $p in /*) echo "MISSING repo-relative $v";; esac; done; done   # an absolute path under a tests/ ancestor can match an exclusion and count zero files
rg --files -g '*.cs' $SRC | head -1 | grep -q . || echo 'MISSING scanned zero files'
L=${L:-$(mktemp -d)}   # the log folder of the index Gate when it ran in this shell, else a fresh one outside the work tree
for f in $SLN $GJ; do [ -f "$f" ] || echo "MISSING OPERAND $f"; done
BASE=$(git symbolic-ref --short refs/remotes/origin/HEAD) || echo 'no origin/HEAD: run git remote set-head origin -a'
GF=1; git grep -q -E -e 'Include="(xunit|NUnit|MSTest|TUnit|Microsoft\.NET\.Test\.Sdk)' -e '<(TestRunnerName|IsTestProject)>' "${BASE:?no origin/HEAD}" -- '*.csproj' '*.props' '*.targets' && GF=0
MTP=0; rg -q -g '*.csproj' -g '*.props' -g '*.targets' -e 'UseMicrosoftTestingPlatformRunner' -e 'EnableMSTestRunner' -e 'EnableNUnitRunner' -e 'TestRunnerName' -e 'Include="TUnit' . && MTP=1
CT=0; rg -q -g '*.csproj' -g '*.props' -e 'Include="Microsoft\.Testing\.Extensions\.CodeCoverage"' -e 'Include="coverlet\.MTP"' . && CT=1

# cs-test-05 [greenfield]: presence of the pin; then the global.json runner section (cs-test-10 covers the VSTest leftovers)
if [ "$GF" = 1 ]; then
  rg -q -g 'Directory.Packages.props' -e 'PackageVersion Include="xunit\.v3\.mtp-v2" Version="4\.0\.2"' . || echo 'missing xunit.v3.mtp-v2 4.0.2'
  jq -e '.test.runner == "Microsoft.Testing.Platform"' "$GJ"
else echo 'incumbent: kept'; fi

# cs-test-06 [mtp]: empty output is the pass, a file carries the argument (a [cli-wrapper] has 3 or more files, 4 with the .Baseline twin); a masked exit code is cs-test-11. MTP only: VSTest rejects the argument
if [ "$MTP" = 1 ]; then
  test "$(rg -l -g '*.csproj' -g '*.props' -g '*.targets' -e 'minimum-expected-tests' . | wc -l)" -ge 1 || echo 'no file carries minimum-expected-tests'
else echo 'not [mtp]: skipped'; fi
# cs-test-06 under VSTest (an incumbent stack), after dotnet test --logger "trx;LogFileName=t.trx" --results-directory "$L/TR": the run executed tests
[ -e "$L/TR/t.trx" ] && { rg -q -e '<Counters total="[1-9]' "$L/TR/t.trx" || echo 'zero tests ran'; }

# cs-test-08 [greenfield]: a runner interface in src
if [ "$GF" = 1 ]; then rg -n -g '*.cs' -e 'interface\s+I\w*Runner' -e 'interface\s+I\w*Process\w*' $SRC; else echo 'incumbent: kept'; fi

# cs-test-09 [greenfield]: framework families in use (must print exactly 1; Arcade names it in TestRunnerName), then test projects with no runner switch (silent when a Directory.Build.props under the tests sets it)
if [ "$GF" = 1 ]; then
  rg -o -N --no-filename -i -g '*.csproj' -g '*.props' -g '*.targets' -e 'Include="(xunit|MSTest|NUnit|TUnit)' -e 'Update="(xunit|MSTest|NUnit|TUnit)' -e '<TestRunnerName>(xunit|MSTest|NUnit|TUnit)' . | rg -o -i -e 'xunit|MSTest|NUnit|TUnit' | tr 'A-Z' 'a-z' | sort -u | wc -l
  rg -q -g 'Directory.Build.props' -e 'UseMicrosoftTestingPlatformRunner' -e 'EnableMSTestRunner' -e 'EnableNUnitRunner' -e 'TestRunnerName' $TESTS \
    || rg --files-without-match -g '*Tests.csproj' -e 'UseMicrosoftTestingPlatformRunner' -e 'EnableMSTestRunner' -e 'EnableNUnitRunner' -e 'TestRunnerName' $TESTS
else echo 'incumbent: kept'; fi

# cs-test-10 [greenfield]: VSTest-era packages, then VSTest-era flags
if [ "$GF" = 1 ]; then
  rg -n -g '*.csproj' -g '*.props' -e 'Include="Microsoft\.NET\.Test\.Sdk"' -e 'Include="xunit\.runner\.visualstudio"' -e 'Include="xunit"' \
    -e 'Include="coverlet\.collector"' -e 'Include="coverlet\.msbuild"' -e 'SkippableFact' .
  rg -n -g '*.yml' -g '*.yaml' -g '*.sh' -g '*.ps1' -g '*.md' -e '--logger' -e '--collect' -e '--settings' -e '--blame' . .github
else echo 'incumbent: kept'; fi

# cs-test-11: a masked exit code (a --ignore-exit-code 8 passes only beside the workflow step named "CS-TEST-11: at least one test ran", the solution-level count), then a continue-on-error on a step that runs tests (R13 judges the step; an upload or report step, the outcome gate and a workflow_dispatch-only regenerate-and-commit job pass)
IGN='a^'; rg -q -e 'CS-TEST-11: at least one test ran' .github && IGN='--ignore-exit-code 8([^0-9]|$)'
rg -n -g '*.yml' -g '*.yaml' -g '*.sh' -g '*.ps1' -g '*.props' -g '*.targets' -e '--ignore-exit-code' -e 'TESTINGPLATFORM_EXITCODE_IGNORE' . .github | rg -v -e "$IGN"
bash "$CHECKS/check-ci-matrix.sh" "$WF" | rg -e 'R13'

# cs-test-12: a NoWarn ID beyond the IL2xxx/IL3xxx trim and AOT IDs, NETSDK1138 (a test project that targets an out-of-support TFM on purpose) and the product's own analyzer IDs (PRODID, a regex such as RF00[0-9]; empty = none), a CS0618 NoWarn or a CS0618 pragma without a reason (an obsolete-API test takes a site pragma with its reason), documentation off in tests, a lowered test-framework analyzer, a test-scoped .editorconfig section count (must print one line, .editorconfig:1), then, only where the section is installed, one line per carve-out ID missing from it. A hit in a project that tests the unsafe path on purpose passes with a reason comment above the NoWarn
PRODID=${PRODID:-}
rg -o -N -H -g '*.csproj' -g '*.props' -e '<NoWarn[^>]*>[^<]*' $TESTS | awk -F'>' -v p="^(${PRODID})$" '{ n = split($NF, a, /[;,]/); for (i = 1; i <= n; i++) if (a[i] !~ /^(\$\(NoWarn\)|IL[23][0-9][0-9][0-9]|NETSDK1138|)$/ && a[i] !~ p) print $1 ": " a[i] (a[i] == "CS0618" ? " (an obsolete-API test takes a site #pragma warning disable CS0618 // reason)" : "") }'
rg -n -g '*.cs' -e '#pragma warning disable\s+CS0618\s*$' $TESTS
rg -n -g '*.csproj' -g '*.props' -e '<GenerateDocumentationFile>\s*false' $TESTS
rg -n -g '.editorconfig' -g '.globalconfig' -g '*.globalconfig' -e 'dotnet_diagnostic\.(xUnit|NUnit|MSTEST|TUnit)[A-Za-z]*[0-9]+\.severity\s*=\s*(none|silent|suggestion)' .
rg -c -g '.editorconfig' -e '^\[.*(test|tests|samples).*\]' .
if grep -qF '[{test,tests,samples}/**.cs]' .editorconfig 2> /dev/null; then
  for id in CA2007 VSTHRD200 CA1707 CS1591 CA1062 CA1848 CA1873 CA1515; do
    awk '/^\[\{test,tests,samples\}\/\*\*\.cs\]/{s=1;next} /^\[/{s=0} s' .editorconfig \
      | grep -q -e "^dotnet_diagnostic.$id.severity = none" || echo "missing $id"; done
else echo 'posture absent: no [{test,tests,samples}/**.cs] section in .editorconfig; the eight carve-out lines are adopted with it (CS-TEST-12)'; fi

# cs-test-13: presence of xUnit1051 at error where xUnit v3 is referenced (a guard against TreatWarningsAsErrors being off), then a dropped token, blocking or async void in tests (generated .g.cs, snapshot output (`*.verified.*`, `*.received.*`, `_snapshots/`) and comment lines are skipped). Where xUnit v2 is the incumbent (no xunit.v3 reference) the framework has no test token and CancellationToken.None is its form, so it is not listed
# .Result is listed only on a task receiver (an Async call, Task.Run, AsTask(), a name ending in Task); a Wait() on a ManualResetEvent or SemaphoreSlim, a .Result on a task that is already complete, a .Result inside an expression tree, a sync framework callback (a void Configure(IApplicationBuilder) that cannot await, so .Wait() stays) and a ConfigureAwait in a helper or fake that forwards a CancellationToken parameter are not listed
rg -q -g '*.csproj' -g '*.props' -e 'Include="xunit\.v3' . && { grep -q -e '^dotnet_diagnostic.xUnit1051.severity = error' .globalconfig || echo 'missing xUnit1051 = error'; }
TOK=(-e 'CancellationToken\.None' -e 'default\s*\(\s*CancellationToken\s*\)'); rg -q -g '*.csproj' -g '*.props' -e 'Include="xunit"' . && ! rg -q -g '*.csproj' -g '*.props' -e 'Include="xunit\.v3' . && TOK=()
rg -n -H -P -g '*.cs' -g '!*.g.cs' -g '!*.verified.*' -g '!*.received.*' -g '!**/_snapshots/**' "${TOK[@]}" -e '\.ConfigureAwait\s*\(' -e '\.GetAwaiter\s*\(\s*\)\s*\.GetResult\s*\(\s*\)' \
  -e 'async void' -e '\.Wait\s*\(\s*\)' -e '(?:Async\s*(?:<[^>]*>)?\s*\((?:[^()]|\((?:[^()]|\([^()]*\))*\))*\)|\bTask\.\w+\s*(?:<[^>]*>)?\s*\((?:[^()]|\((?:[^()]|\([^()]*\))*\))*\)|\.AsTask\s*\(\s*\)|\b\w*(?i:task))\s*\.Result\b' $TESTS | rg -v -e '^[^:]+:[0-9]+:\s*(//|/\*|\*)' \
  | while IFS=: read -r f n rest; do awk -v n="$n" -v r="$rest" 'BEGIN { k = (r ~ /\.Wait *\(|GetResult/) ? "blk" : (r ~ /ConfigureAwait/ ? "cfg" : "tok") }
      NR <= n && cap { d = d " " $0; if ($0 ~ /\)/) cap = 0 }
      NR <= n && /^[ \t]*((public|private|protected|internal|static|override|virtual|sealed|async|extern|unsafe|new)[ \t]+)*[A-Za-z_][A-Za-z0-9_<>,.?\[\]]*[ \t]+[A-Za-z_][A-Za-z0-9_]*[ \t]*(<[^>]*>)?[ \t]*\(/ && !/^[ \t]*(return|await|var|new|else|throw|using|yield|case|goto)[ \t]/ { d = $0; cap = ($0 !~ /\)/) }
      NR == n { if (k == "blk") exit !(d ~ /void[ \t]+[A-Za-z_]*Configure|void[ \t]+[A-Za-z_]+[ \t]*\([^)]*(IApplicationBuilder|IWebHostBuilder|IHostBuilder|IServiceCollection|IConfigurationBuilder|ILoggingBuilder|ListenOptions)/)
                if (k == "cfg") exit !(d ~ /CancellationToken[ \t]+[A-Za-z_]/)
                exit 1 }' "$f" || echo "$f:$n:$rest"; done

# cs-test-15: a test method whose first statement is a guarded early return (a guard clause outside a test method is not flagged)

# cs-test-16: FluentAssertions at 8 or later, written or reached through a property, then in the restored closure (a failed list is not a pass).
# dotnet list restores implicitly and writes obj/ and the packages folder, so restore first and expect those writes. MSB1003, MSB1009 and MSB1011 name a wrong SLN; NETSDK1045 means the installed SDK is older than a target framework (run from the build root so global.json applies, or fix the toolchain); none of them is a finding
pk() { rl=$(mktemp); dotnet restore "$SLN" --tl:off --interactive false --disable-build-servers -nologo -v:q > "$rl" 2>&1 || { echo "restore failed, log $rl: $(grep -Eo 'MSB1003|MSB1009|MSB1011|NETSDK1045|NU[0-9]{4}' "$rl" | sort -u | tr '\n' ' ')"; return 1; }; dotnet list "$SLN" package --include-transitive --no-restore 2>&1; }
rg -n -g '*.csproj' -g '*.props' -e 'Include="FluentAssertions"\s+Version="([89]|[1-9][0-9])\.' -e 'Include="FluentAssertions"\s+Version="\$\(' .
out=$(pk) || echo "package listing failed, an empty result below proves nothing: $out"
```

## What Agents Get Wrong Here

1. **`coverlet.collector` with `--collect:"XPlat Code Coverage"`, or `coverlet.msbuild`.** Green with no report (`CS-TEST-10`, `CS-TEST-18`).
2. **A red test-project build turned green with `<NoWarn>CA1707;CS1591</NoWarn>`, `<NoWarn>CA1515</NoWarn>`, `GenerateDocumentationFile=false`, or by renaming `E1_` tests** (`CS-TEST-12`, `CS-TEST-04`).
3. **`.ConfigureAwait(false)`, `.Result` or `CancellationToken.None` copied from library code into tests** (`CS-TEST-13`).
4. **Accepting a snapshot** with `mv X.received.txt X.verified.txt`, a hand edit, or `AutoVerify()` "to bootstrap" (`CS-TEST-22`).
5. **The latest FluentAssertions (8.x), an unversioned Moq, or `Verify.XunitV3` 33.x then `Verify_SponsorshipLicenseIgnored`** (`CS-TEST-16`, `CS-TEST-17`, `CS-TEST-23`).
6. **A coverage threshold near the first number seen, then hollow tests or `[ExcludeFromCodeCoverage]` to reach it** (`CS-TEST-20`).
7. **A generated-code denominator, a fixed `--coverage-output` on a multi-TFM project, a relative `--coverage-settings`, `dotnet-coverage merge`** (`CS-TEST-18`, `CS-TEST-19`).
8. **An early `return;` for an unmet precondition, a hallucinated MSTest `Assert.Skip`, or the contract tier as `[Fact(Skip="needs tool")]`** (`CS-TEST-15`, `CS-TEST-07`, `CS-TEST-06`).
9. **`--ignore-exit-code 8` or `continue-on-error: true` to fix a red run**, rather than the id-plus-outcome-gate form (`CS-TEST-11`).
10. **Environment variables set in parallel xUnit tests** (`CS-TEST-14`, `CS-TEST-31`).
11. **Mocking `Process` behind `IProcessWrapper`**, or `ReferenceOutputAssembly="false"` on the dummy (`CS-TEST-02`, `CS-TEST-03`, `CS-TEST-08`).
12. **The VSTest-era stack: `Microsoft.NET.Test.Sdk`, xUnit v2, `--logger trx`, `--blame-hang-timeout`** (`CS-TEST-05`, `CS-TEST-10`).
13. **`os: [ubuntu-latest, windows-latest, macos-latest]` called cross-platform, with floating labels, `fail-fast` left default, or `DOTNET_ROLL_FORWARD: Major` to fix "framework not found"** (`CS-CI-01` to `CS-CI-04`).
14. **A `container: mcr...-alpine` job, a floating `10.0-alpine` tag, an `actions/cache` for NuGet keyed on the OS alone** (`CS-CI-05`, `CS-CI-07`).
15. **A property with FsCheck's default `string`, a pinned seed, a POSIX literal root, or `iter: 100000` on a spawning property** (`CS-TEST-26`).
16. **A snapshot of a decoded DTO or an exception "to prove the mapping"** (`CS-TEST-21`).
