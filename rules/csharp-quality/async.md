# C# Async Contract

Rows bind to SDK 10.0.401 on net8.0 and net10.0 (measured 2026-10-11), with VS.Threading.Analyzers 18.7.23,
IDisposableAnalyzers 4.0.8, BannedApiAnalyzers 5.6.0 and Meziantou.Analyzer 3.0.297 (MA0004 only) as `dotnet-build`
pins them. macOS and Windows behaviour is `unverified: not run`. .NET 11 runtime-async is covered where a row says so.

Owns the async contract of a library: token signature, forwarding and classification, ConfigureAwait, ownership,
blocking, the async gate IDs, shared state, the thread-safety promise and pump callbacks. Not owned here: the
severity lines, the `src` versus `tests` ConfigureAwait split and the bans are the posture files of `dotnet-build`
(`analyzers.globalconfig`, `analyzers.editorconfig`, `BannedSymbols.txt` and `BannedSymbols.Src.txt`). This file names the IDs and symbols and
never restates a line. The test-project carve-out is `CS-TEST-12`, the stderr callback contract is `CS-OBS-27` and
`CS-OBS-28`, the install race is `CS-BIN-12`, process launch, kill and drain are `CS-PROC`, exception types are
`CS-ERR`, and the PublicAPI gate is `CS-API`. **SDK** means a library that wraps a CLI. Example names from the
reference consumer (`OcxClient`, `OnStderrLine`, `project_locked`) may stay: rename them once.

`CS-ASYNC-24`, `CS-ASYNC-28` and `CS-ASYNC-31` are retired, not reused. The first two moved to the reference
consumer's design record, the third duplicated `CS-OBS-28`.

`CS-ASYNC-05`, `CS-ASYNC-10` and `CS-ASYNC-18` are retired, not reused. An analyzer at error enforces each, and
`CS-ASYNC-19` keeps their non-obvious clauses.

## Reading the Checks

- **`G`** is the build gate in the `DN-RULE-01` form: `timeout 900 dotnet build --tl:off --interactive false --disable-build-servers -nologo -v:q --no-incremental > build.log 2>&1; echo $?`.
  Exit 0 is the pass. "`G` fires `CA1068`" means `error CA1068` is in `build.log`; `rg -o -e 'error [A-Za-z]+[0-9]+' build.log` lists them.
- **Posture** means the four `dotnet-build` posture files installed: `analyzers.globalconfig`, `analyzers.editorconfig`, `BannedSymbols.txt` and `BannedSymbols.Src.txt`. Every analyzer row was watched red on a plant and green on its twin, on net8.0 and net10.0, with the posture files and warnings-as-errors (measured 2026-10-11).
- **C01..C32** are the commands of [Check Commands](#check-commands), run from the repository root. `SRC` and `TESTS` are the operand variables of the index Conventions, written unquoted (`$SRC`); the first line of the block aborts on an empty operand (an empty `$TESTS` made `rg` read stdin and block) and the next fails on a missing directory, because `rg` exit 2 is never a pass. `SRC` names shipped library projects only, never benchmarks, samples, examples or apps (refit's `src/benchmarks` and `src/examples` gave 63 of 75 C01d hits). Every shipped-code scan carries the index's test exclusion and `--iglob '!*.{g,generated,designer}.cs'`, which skips generated output. Replace the filename globs of C20, C27, C29 and C32 with the project's file names: each of those cells has a guard line that prints when its glob selects no file. Every call pattern allows whitespace before `(`, because MailKit writes `Name (args)`; a spaced plant of each sits on the variants file.
- **Applicability.** Every row leads with its tag (index Conventions). `[always]` binds every repository this file loads for. `[library]` binds a project consumed as a package or API: an `[app]` has no consumers, so its public surface is not bound. `[cli-wrapper]` binds a library whose purpose is wrapping one tool, also where it appears mid-row on one sentence. `[greenfield]` binds a project whose every shipped TFM is net8.0 or newer; a row that needs an API its lowest TFM lacks names the fallback. `CS-ASYNC-20` and `CS-ASYNC-27` bind a wrapper that starts one process per call; a client over one long-lived multiplexed child keeps the exception in each row.
- **Scope.** The rows bind `Task` and `ValueTask`. A custom awaitable (UniTask) is outside the task asynchronous pattern, so its `params` and `WaitAsync` shapes are not hits.
- A cell that says **heuristic** is judged by reading. A **test** is the adopter's; where it was also run, the cell says so.
- **Defaults, the adopter may override:** net8.0 and net10.0 until .NET 8 end of support (2026-11-10), async-only v1 surface, Meziantou adopted with mode `None` and per-rule lines. `ConfigureAwaitOptions` and `WaitAsync(timeout, TimeProvider, token)` exist from net8.0. `Task.WaitAll(ReadOnlySpan)` is .NET 9+. `System.Threading.Lock` is absent on net8.0.

| CS-ASYNC-01 | [library] Every public async method that does I/O, waits or loops ends with exactly one `CancellationToken cancellationToken = default`. ## What Agents Get Wrong Here

Ranked by corpus prevalence times how likely an agent emits it unprompted (research 2026-10-11).

1. **A convenience sync method doing `XAsync().GetAwaiter().GetResult()`, defended with "ConfigureAwait(false) makes it safe".** 273 `GetAwaiter().GetResult()` and 235 `.Result` in the corpus. `CS-ASYNC-14`, `CS-ASYNC-15`.
2. **ConfigureAwait missing in the library, or sprinkled into tests; CA2007-clean code assumed done while `.WithCancellation(token)` and `await using (x)` stay bare.** 82% of the corpus, bimodal by severity. `CS-ASYNC-06`.
3. **A token named `ct`, not last, or missing on convenience wrappers.** 8.5% of corpus parameters. `CS-ASYNC-01`.
4. **`Lazy<Task<T>>`, `PublicationOnly` "so exceptions are not cached", or `AsyncLazy<T>`.** 4 of 35 exemplar repos. `CS-ASYNC-21`.
5. **An undisposed `Process` or source in a `return p.ExitCode;` helper, or the full `Dispose(bool)` ritual on a managed class.** CA2000 misses the first. `CS-ASYNC-11`, `CS-ASYNC-12`.

7. **Shared init started with the first caller's token, or reset on `IsFaulted` only.** `CS-ASYNC-22`, `CS-ASYNC-23`.
8. **"Back-pressure" through `Channel.CreateBounded` in the pump, or `catch (Exception) { }` around the callback.** `CS-ASYNC-30`, `CS-OBS-28`.
