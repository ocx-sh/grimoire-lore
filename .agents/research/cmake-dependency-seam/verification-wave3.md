# Verify wave 3: the dependency seam

Binaries: CMake 3.31.12, 4.3.4 and 4.4.2 through `ocx package exec kitware/cmake:<line>`, ninja from `ninja-build/ninja`, gcc 15.2, pkgconf 2.3.0. Primary sources are the `--help-*` output of each binary and the modules under each binary's `CMAKE_ROOT`. Conan 2.32.0's `blocks.py` came from `raw.githubusercontent.com/conan-io/conan/2.32.0`. GitHub release and issue state came from `api.github.com`. The corpus clones are at the 2026-09-26 SHAs. Every run is dated 2026-09-26.

Measurement sources and a `run.sh` per experiment are in [`scratch/verify-dependency-seam/`](scratch/verify-dependency-seam/). Scripts resolve paths relative to their own directory and run from the lore worktree root. The C1-C6 re-run used verify wave 2's copy (`c/run.sh`), which is identical to [`scratch/dependency-seam-consolidation/`](scratch/dependency-seam-consolidation/) with its path prefix rewritten. The R1-R3 re-runs used [`scratch/dependency-seam-revision/`](scratch/dependency-seam-revision/) with 4.3 added to each loop.

New experiments in this wave:
