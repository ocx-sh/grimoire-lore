# C# set: review finding classes (phase 8)

The 45 cross-unit findings of the phase-8 review, plus 1 the consistency pass found (46), grouped by mechanism.
Held-out rounds converge on classes, not on instances. A later round checks each class with the check in its row
before it reads for new findings. Counts are cross-unit findings only. Per-unit totals are in
`scratch/review-receipt.json`.

Contradiction leads at 17 of 46. It comes from the authoring split: 13 drafters each own one family, and no single
drafter sees both halves of a shared noun. The cheapest durable check is to run each unit's checks against the other
units' mandated code. A pass that only reads the rows does not catch it.
