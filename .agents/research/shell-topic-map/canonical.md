## Summary

- The standards baseline moved: [POSIX.1-2024](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/V3_chap02.html) standardises `set -o pipefail`, `$'...'`, `read -d`, `find -print0`, `xargs -0/-r`, `sed -E`, `realpath`/`readlink`, `printf` numbered conversions, and removes `test -a`/`-o`. It still has no `mktemp`, `stat`, `which`, `sed -i`, `date -d`, `grep -P`, `local`, `[[` (utility pages for mktemp/stat/which return 404).
- The de-facto `/bin/sh` lags the standard: Debian sid and Ubuntu 26.04 still ship dash 0.5.12-12, which lacks pipefail and `$'..'` (added upstream in 0.5.13, 2025-09-21). [Debian Policy 10.4](https://www.debian.org/doc/debian-policy/ch-files.html) still promises POSIX.1-2017 plus `echo -n`, `test -a/-o`, `local`, XSI `kill`/`trap`.
- `set -o pipefail 2>/dev/null` is not a safe probe: it terminates dash 0.5.12 (exit 2) and posh (exit 1) because a special-builtin error is fatal. Use `(set -o pipefail) 2>/dev/null && set -o pipefail`. `$'a\tb'` is silently misparsed (literal `$a\tb`) by dash 0.5.12, yash 2.52 and posh. Measured.
- ShellCheck 0.11.0 contradicts POSIX.1-2024 under `-s sh`: it reports SC3003 (`$'..'`), SC3040 (pipefail) and SC3045 (`read -d`) though all three are now defined. A gate built on SC3xxx needs an actual dash/posh run behind it.
- macOS `/bin/bash` is 3.2.57 **(macOS, read-only for BSD userland; bash 3.2 semantics measured in a container)**. Bash 3.2 lacks associative arrays, `mapfile`, `${x,,}`, `[[ -v ]]`, negative indices, `&>>`, `|&`, namerefs, `wait -n`, `${x@Q}`, `inherit_errexit`, `lastpipe`; empty `"${a[@]}"` under `set -u` fails through bash 4.2.
- `set -e` is not one semantics: exemptions (conditions, `&&`/`||` lists, non-last pipeline stages, `!`, functions called in a condition) are specified; `local x=$(false)` masks status in every shell with `local`; bash 3.2 does not abort the parent when a `( false; ... )` subshell fails; `(( 0 ))` obeys -e only from 4.1; command substitutions inherit -e only in POSIX mode or with `inherit_errexit` (4.4+). Measured.
- GitHub Actions `run:` defaults are exact and differ: unspecified Linux/macOS = `bash -e {0}` (no pipefail); `shell: bash` = `bash --noprofile --norc -eo pipefail {0}`; `sh -e {0}`; pwsh prepends `$ErrorActionPreference = 'stop'`; Windows default is pwsh. Task (go-task) runs `cmds` in embedded mvdan/sh, never the user's shell.
- "Works on Alpine" is weak evidence of POSIX: busybox ash (ASH_BASH_COMPAT default y) accepts `[[`, `function`, `${v//p/r}`, `${v:1:2}`, `==`, `source`, `let`, `<(...)`; it rejects here-strings, arrays, `$(<file)`, `printf %q`. Bash `--posix` still accepts arrays and `[[`.
- Arithmetic is not portable at the edges: `$((010))` is 8 in dash/ash/bash/yash/posh/zsh-sh but 10 in mksh and ksh93u+m; `$((08))` errors in dash/ash/bash/posh but is 8 in mksh/ksh93/yash; `9223372036854775807+1` wraps, is 0 (mksh) or a float (ksh93u+m). Measured.
- `echo` is XSI-only for escapes: dash prints `-e x<TAB>y` for `echo -e 'x\ty'`; yash prints `-n`/`-e` literally. `printf '%s\n'` is the portable form. `printf '%2$s %1$s'` works only in ksh93u+m and zsh among probed shells.
- Windows PowerShell 5.1 and pwsh 7 differ in ways that break scripts at parse time or silently: ternary, `&&`/`||`, `??` are parse errors in 5.1; `$IsWindows` is `$null`; `>` and `Out-File` write UTF-16LE with BOM, `Set-Content` writes ANSI; a BOM-less UTF-8 script is read as ANSI. pwsh 7 writes UTF-8 without BOM. Measured on the Windows host.
- PowerShell lifecycle (docs, ms.date 2026-08-13): 7.6 LTS (2026-03-18) supported to 2028-11-14; 7.4 LTS and 7.5 end 2026-11-10; 7.7 preview on .NET 11; Windows ships only 5.1. Recheck after November 2026.
- Alt shells are moving targets: fish 4.0 (Rust) through 4.9.3, `{ ...; }` grouping from 4.1, `?` glob off from 4.0; nushell 0.116.1 (2026-10-04) enabled pipefail by default in 0.111 and still rejects `&&`; elvish last released 0.21.0 on 2024-08-14 and is near-dormant.
- zsh docs now say 5.9.2 (released 2026-07-12); master NEWS lists an unreleased 5.10 line with refined ERR_EXIT/ERR_RETURN. Invoked as `sh`, zsh sets SH_WORD_SPLIT, KSH_ARRAYS, NO_NOMATCH, BSD_ECHO and drops its normal startup files.
- Autoconf's manual remains the best catalogue of boring-but-bite hazards (echo, test arity, `$@`, here-doc `<<-`, mktemp fallback, mv atomicity, locale pinning, `sed`/`grep`/`find` portable flag sets) but is partly stale: it says `$10` in dash is the tenth parameter (measured: all probed shells give `${1}0`) and that macOS `sh` returned to zsh in 10.15 (contradicted by Apple's page).
- The community pitfall lists the owner pointed at ([Wooledge BashPitfalls](https://mywiki.wooledge.org/BashPitfalls), 65 items; [BashFAQ/105](https://mywiki.wooledge.org/BashFAQ/105)) map onto roughly a dozen root causes: unquoted expansion, `ls`/`for` parsing, subshell variable loss, masked statuses, GNU-only flags, non-atomic writes. They are secondary sources; every claim used here is backed by a spec or probe.
- Hypotheses: H5 (Actions defaults) confirmed; H8 (PowerShell lifecycle) confirmed; H6 (dash/bashism) supported by measurement; H9 (nu churn) supported; H7 partly confirmed (Apple page) and contradicted by the stale Autoconf text; frame era facts contradicted: nu is 0.116.1 not 0.116.0, zsh docs show 5.9.2, dash upstream is at 0.5.13.5.

## Survey

### 2.1 POSIX.1-2024 (Issue 8): what changed for scripts

Source: [XCU chapter 2](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/V3_chap02.html) and the utility pages.

- Added: `set -o pipefail` (Austin Group defect 789); `$'...'` dollar-single-quotes (2.2.4); `read -d delim` ([read](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/read.html)); `find -print0`, `-iname`, `-mount` ([find](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/find.html)); `xargs -0` and `-r` ([xargs](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/xargs.html)); `sed -E` and the `i` flag ([sed](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/sed.html)); `test -ef`; `printf` numbered conversions `%n$` ([printf](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/printf.html)); `realpath [-E|-e]` and `readlink [-n]` as new utilities; `head -c`, `tail -r`.
- Removed: `test -a` and `-o` and the parenthesised forms ([test](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/test.html), defect 1330).
- Clarified: `exit` inside a trap uses the pre-trap `$?` (interpretation 1602); `set -e` wording (defect 1150); `sort`/`ls` ties broken bytewise (defect 1070).
- Absent: `mktemp`, `stat`, `which` (pages return 404 on 2026-10-10); `sed -i`, `date -d`, `grep -P`, `local`, `[[`, `echo -e` (escapes remain XSI-only).
- Exit statuses: 126 not executable, 127 not found, >128 signal ([2.8.2](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/V3_chap02.html)).
- Consequence: any rule saying "POSIX sh lacks pipefail/`$'..'`/`read -d`" is now wrong against the standard and still right against dash 0.5.12, posh and yash 2.52. The rule must say which one it means.

### 2.2 The Autoconf portable-shell catalogue (read with a dating filter)

Source: [Autoconf manual, ch. 11](https://www.gnu.org/software/autoconf/manual/autoconf.html). Text mentions 2024 and 2025 and macOS Sequoia 15.1.1, but most entries target Solaris 10, AIX, HP-UX shells **(historical)**. Still valid:

- `echo`: use `printf '%s\n'`; never `echo` with options or backslashes.
- `set -e` inside functions and `||` contexts is "asking for surprises"; avoid `set -` forms.
- `trap`: only signals 1 2 13 15 portably; `trap - 1 2 13 15` to reset; `(exit 42); exit 42` idiom for exit status inside a trap; bash and zsh disagree on `$?` seen in an EXIT trap.
- `test`: at most four arguments; avoid `-a`/`-o`; `-nt`/`-ot` ignore subsecond timestamps on macOS `sh` through Sequoia 15.1.1 **(macOS, read-only)**.
- Locale: `LC_ALL=C` for deterministic ranges and sort; never unset IFS; set CDPATH to empty; LINENO is unreliable.
- Patterns and quoting: `[!...]` not `[^...]`; `[[:lower:]]` rather than `[a-z]`; brace expansion is not POSIX; here-doc `<<-` strips tabs only; `"$@"` vs `${1+"$@"}`; `${10}` form; `$(( ))` octal/hex divergence.
- Files: descriptors above 9 are not portable in dash; `mktemp` fallback `(umask 077 && mktemp -d "$TMPDIR/fooXXXXXX")` falling back to `mkdir "$TMPDIR/foo$$-$RANDOM"`; `mkdir -p` races; `mv` across filesystems is not atomic; Windows reserved filenames and MSYS paths.
- Tools: `sed` portable options are `-e -f -n` (the manual notes POSIX standardised `-E` in 2024); `find -printf`, `-maxdepth`, `-follow` are GNU-only; `grep` portable options `-c -l -n -v`; `sort` order is locale-dependent; `tr` in multibyte locales; busybox `tr` lacks `[x*n]`.
- Stale in this corpus: `$10` in dash (measured today: `a0` in every probed shell, so it is `${1}0`); "macOS sh changed back to zsh in 10.15" (contradicted by [Apple's page](https://support.apple.com/en-us/102360): default sh is bash 3.2 in POSIX mode, selectable via `/var/select/sh` among bash, dash, zsh) **(macOS, read-only)**.

### 2.3 Bash: version gates, compat levels, POSIX mode

Sources: [NEWS](https://git.savannah.gnu.org/cgit/bash.git/plain/NEWS), [COMPAT](https://git.savannah.gnu.org/cgit/bash.git/plain/COMPAT), [CHANGES](https://git.savannah.gnu.org/cgit/bash.git/plain/CHANGES), [manual](https://www.gnu.org/software/bash/manual/bash.html), [POSIX mode](https://www.gnu.org/software/bash/manual/html_node/Bash-POSIX-Mode.html).

| Version | Gate |
|---|---|
| 4.0 | associative arrays (`declare -A`), `mapfile`/`readarray`, `coproc`, `&>>`, `\|&`, `;&`/`;;&`, `globstar`, `${v^^}`/`${v,,}`, compat levels |
| 4.1 | `{var}` redirections, `printf -v`, `read -N`, `[[`/`((` subject to `set -e`, `BASH_XTRACEFD` |
| 4.2 | `[[ -v var ]]`, negative array indices, `${v:o:-n}`, `printf '%(fmt)T'`, `$'\u'`, `shopt -s lastpipe` |
| 4.3 | namerefs (`declare -n`), `wait -n`, `BASH_COMPAT` variable |
| 4.4 | `${v@Q}`, `shopt -s inherit_errexit`, `local -`, `mapfile -d`, empty-array `set -u` fix, root shells ignore inherited PS4 |
| 5.0 | `EPOCHSECONDS`, `EPOCHREALTIME`, `BASH_ARGV0`; last version with per-level `compatNN` shopts |
| 5.1 | `SRANDOM`, `${v@U}`/`@L`/`@u`, `PROMPT_COMMAND` may be an array, `wait -p`, pipes for here-documents, glob sort byte tie-break; `BASH_COMPAT` is the only compat knob |
| 5.2 | `patsub_replacement` (`&` in replacement), `globskipdots`, `@k`, `command -p` unhashed, `array_expand_once` |
| 5.3 | `${ cmd; }` function substitution, `GLOBSORT`, `source -p`, `BASH_MONOSECONDS`, `trap -P`, `[[` regex compile errors, `exit` in trap per interp 1602 |

Measured (bash 3.2/4.0/4.2/4.4/5.x, `bashfeat.sh`): 3.2 fails every 4.x+ row above; `${x@Q}` fails until 4.4; `${ cmd; }` works only on 5.3.

- POSIX mode: special-builtin errors exit; `inherit_errexit` on; `ENV` read; aliases always expanded; function names may not equal special builtins; process substitution allowed from 5.1; 5.3 no longer requires function names to be identifiers.
- Startup files: login reads `/etc/profile` then the first of `~/.bash_profile`, `~/.bash_login`, `~/.profile`; non-login interactive reads `~/.bashrc`; non-interactive reads `$BASH_ENV`; invoked as `sh` reads `$ENV` in POSIX mode.
- `set -e` text: ignored for conditions, `&&`/`||` lists except the last command, non-last pipeline commands, `!`; a compound command or function run in an ignored context ignores -e entirely.
- Compat levels (`BASH_COMPAT=44`, `shopt -s compat44`) are a temporary migration tool per COMPAT.

### 2.4 Dash, busybox ash, mksh, ksh93u+m, yash, posh

Probe matrix (`matrix.sh posix`, 2026-10-10): dash 0.5.12 (Debian 12), busybox ash 1.35 and 1.37, mksh R59c, ksh93u+m (2023 build and 1.0.10), yash 2.52, posh 0.14.1, bash 3.2 and 5.2 `--posix`, zsh 5.9 `--emulate sh`.

| Probe | Result |
|---|---|
| `(set -o pipefail)` (safe probe) | unsupported in dash 0.5.12 and posh; others support |
| `$'a\tb'` | dash 0.5.12, yash 2.52, posh: literal `$a\tb`; others work |
| `read -r -d :` | dash rc 2, yash rc 2, posh rc 1; others work |
| brace expansion | absent: dash, ash, yash, posh, zsh-sh; present: mksh, ksh93, bash (ksh93 has ranges, mksh not) |
| `echo -e` | dash prints `-e x<TAB>y`; yash prints `-e`/`-n` literally |
| `printf '%2$s %1$s'` | works: ksh93u+m, zsh; not: busybox ash, mksh, yash, bash |
| `local` | absent in ksh93u+m (both) and posh |
| `$((010))` / `$((08))` | see Summary |
| `trap ... ERR` | works in ash, mksh, ksh93, bash, zsh; not dash, posh, yash |

Note: the unsafe probe `set -o pipefail 2>/dev/null` exits dash 0.5.12 (2) and posh (1); the subshell probe is safe everywhere. yash gained its POSIX-2024 items from 2.59; the probed 2.52 predates them.

- dash: upstream 0.5.13 (2025-09-21) adds `pipefail`, `$'...'`, multibyte support; latest 0.5.13.5 (2026-07-18); includes CVE-2026-31323 fixes ([git log](https://git.kernel.org/pub/scm/utils/dash/dash.git/log/), [man page](https://git.kernel.org/pub/scm/utils/dash/dash.git/plain/src/dash.1)). Distros: Debian sid [0.5.12-12](https://packages.debian.org/source/sid/dash), Ubuntu 26.04 [0.5.12-12](https://packages.ubuntu.com/source/resolute/dash).
- busybox ash ([ash.c](https://raw.githubusercontent.com/mirror/busybox/master/shell/ash.c)): derived from dash; config `ASH_BASH_COMPAT` (y), `ASH_BASH_SOURCE_CURDIR` (n), `ASH_BASH_NOT_FOUND_HOOK` (y), `ASH_ALIAS`, `ASH_RANDOM_SUPPORT`, `ASH_ECHO`, `ASH_PRINTF`, `ASH_TEST`, `ASH_IDLE_TIMEOUT`. Command substitution does not inherit `-e` (`echo $(false; echo hi)` prints `hi`).
- mksh ([man](https://manpages.debian.org/trixie/mksh/mksh.1.en.html)): `local` aliases `typeset`; dynamic scoping; leading 0 not octal except in POSIX mode; `10#` forces decimal.
- ksh93u+m ([NEWS](https://raw.githubusercontent.com/ksh93/ksh/dev/NEWS), [README](https://raw.githubusercontent.com/ksh93/ksh/dev/README.md)): active dev branch (entries to 2026-10-10); POSIX-2024 changes only in `posix` mode; `exec` no longer exits the shell per POSIX-2024; static scoping, locals only in Korn-style functions.
- yash ([POSIXly-correct doc](https://magicant.github.io/yash/doc/posix.html), [NEWS](https://raw.githubusercontent.com/magicant/yash/trunk/NEWS)): 2.59 (2025-05-13) adds `read -d`, `trap -p`, exit-in-trap status, refuses `test -a/-o` and parentheses in POSIXly-correct mode, never globs `.`/`..`; 2.60 (2025-09-15), 2.61 (2026-03-03). Dropped from Debian 13 (per the frame).
- posh: strictest Debian policy checker; lacks `local`, pipefail, `$'..'`, `read -d`.

### 2.5 zsh

Sources: [Invocation](https://zsh.sourceforge.io/Doc/Release/Invocation.html), [Options](https://zsh.sourceforge.io/Doc/Release/Options.html), [Files](https://zsh.sourceforge.io/Doc/Release/Files.html), [NEWS](https://raw.githubusercontent.com/zsh-users/zsh/master/NEWS).

- Docs state 5.9.2 released 2026-07-12; master NEWS header "Changes since 5.9" is the unreleased 5.10 line.
- 5.10 changes: refined `ERR_EXIT`/`ERR_RETURN` (aligned with POSIX-2017 `set -e`; `! f` never triggers; `always` ignores them), emacs default keymap, restricted mode removed, `${ cmd }` and `${| }`, PCRE2, nameref, `zparseopts -G`, `getopts -p`. Flag as not released.
- Invoked as `sh`/`ksh`: sets `NO_BANG_HIST`, `KSH_ARRAYS`, `SH_WORD_SPLIT`, `SH_GLOB`, `POSIX_BUILTINS`, `NO_NOMATCH`, `BSD_ECHO`, others.
- Startup order: `/etc/zshenv`, `$ZDOTDIR/.zshenv`, login-only `zprofile`, interactive `zshrc`, login-only `zlogin`. `.zshenv` runs for every instance including scripts.
- Options `PIPE_FAIL`, `ERR_EXIT`, `ERR_RETURN`, `LOCAL_OPTIONS`, `LOCAL_TRAPS` exist and are per-function scoped with `emulate -L`.

### 2.6 fish

Sources: [for bash users](https://fishshell.com/docs/current/fish_for_bash_users.html), [relnotes](https://fishshell.com/docs/current/relnotes.html), [language](https://fishshell.com/docs/current/language.html), [CHANGELOG](https://raw.githubusercontent.com/fish-shell/fish-shell/master/CHANGELOG.rst).

- Current 4.9.3 (2026-09-08). Releases: 4.0 2025-02-27, 4.1 2025-09-27, 4.2 2025-11-10, 4.3 2025-12-28, 4.4 2026-02-03, 4.5 2026-02-17, 4.6 2026-03-28, 4.7 2026-05-05, 4.8 2026-06-24, 4.9 2026-09-03. Debian 12 ships 3.6.0, Debian 13 ships 4.0.2 (per the frame).

- Model differences (docs): no word splitting, no heredocs, no subshells, `string` replaces `${x%..}`, `math` replaces `$((..))`, `psub` for process substitution, `$status`/`$argv`/`$fish_pid`, `fish_trace`.

### 2.7 nushell

Sources: [coming from bash](https://www.nushell.sh/book/coming_from_bash.html), [hooks](https://www.nushell.sh/book/hooks.html), [configuration](https://www.nushell.sh/book/configuration.html), release posts [0.110](https://www.nushell.sh/blog/2026-01-17-nushell_v0_110_0.html), [0.111](https://www.nushell.sh/blog/2026-02-28-nushell_v0_111_0.html), [0.114](https://www.nushell.sh/blog/2026-07-04-nushell_v0_114_0.html), [0.116](https://www.nushell.sh/blog/2026-09-26-nushell_v0_116_0.html).

- Current 0.116.1 (2026-10-04); 0.116.0 (2026-09-26). The frame said 0.116.0.
- 0.108 (2025-10-15): experimental `pipefail`, `enforce-runtime-annotations`. 0.110 (2026-01-17): `$nu.temp-path` -> `$nu.temp-dir`, `$nu.home-path` -> `$nu.home-dir`; `cp`/`mv`/`du` `*` no longer matches dotfiles. 0.111 (2026-02-28): pipefail on by default (#17449), `finally`, `let` behaves differently inside pipelines. 0.112: `%` sigil, `from md`. 0.113 (2026-05-23): kill shorthand changed, `mkdir -v` returns a table. 0.114 (2026-07-04): submodules no longer implicitly imported, POSIX `--` option parsing, `enforce-runtime-annotations` opt-out, `str upcase` deprecated for `str uppercase`. 0.115 (2026-08-15): YAML 1.2 default (`--spec 1.1`). 0.116: unified custom completions (token/place/buffer params), tui commands, `nu --dap`.
- Measured: `echo a && echo b` is a parse error ("&& not supported") in 0.105.1 and 0.116.0; `^false | ^cat` continues in 0.105.1 (LAST_EXIT_CODE 0) but aborts the script, exit 1, in 0.116.0; `str upcase` warns in 0.116 and works silently in 0.105.1; `$nu.temp-path` still works in 0.105.1. The book's `set -o pipefail` row says "(default behavior)", true since 0.111.
- Hooks (`pre_prompt`, `pre_execution`, `env_change`, `display_output`, `command_not_found`) are interactive only. Startup: `env.nu` historical; best practice is `config.nu` plus autoload dirs (`$nu.vendor-autoload-dirs`, `$nu.user-autoload-dirs`), plus `login.nu`; `NU_LIB_DIRS` const.

### 2.8 elvish

Sources: [unique semantics](https://elv.sh/learn/unique-semantics.html), [command ref](https://elv.sh/ref/command.html), [0.21.0 notes](https://elv.sh/blog/0.21.0-release-notes.html), [0.20.0 notes](https://elv.sh/blog/0.20.0-release-notes.html).

- Last release 0.21.0 (2024-08-14); `v0.22.0-dev` tag; last repo commit 2025-07-14 (near-dormant).

### 2.9 PowerShell

## Contested

1. **POSIX.1-2024 vs Debian Policy vs ShellCheck**: the standard says pipefail, `$'..'`, `read -d` exist and `test -a/-o` do not; Debian Policy says the reverse for `test -a/-o` and says POSIX.1-2017; ShellCheck sides with 2017. Resolution depends on which shell versions the rule targets.
2. **Autoconf staleness**: `$10` in dash and "macOS sh is zsh" are contradicted by measurement and Apple; do not copy Autoconf entries without a date filter.
3. **`set -e`**: Debian Policy says every script should use it; [BashFAQ/105](https://mywiki.wooledge.org/BashFAQ/105) and BashPitfalls 60 call it unreliable. The measured exemptions support the critique; the usual compromise is explicit `|| exit` plus `trap ... ERR` where available.
4. **`local` and `test -a`**: Debian-allowed, not POSIX; `local` is missing in ksh93u+m and posh.
5. **`function` keyword**: accepted by busybox ash, bash, ksh, zsh; rejected by dash, yash, posh.
6. **Bash 3.2 floor vs requiring Homebrew bash 5**: depends on installer context **(macOS, read-only)**.
7. **nu book vs experimental pipefail**: the book row says "default behavior", true only since 0.111.
8. **`curl | sh` and execution policy**: security posture is a policy call; PowerShell execution policy applies only on Windows and is not a security boundary per its own docs.
9. **Dormant vs supported shells**: elvish near-dormant; yash dropped from Debian 13 (per the frame). Support tier is a project decision.
10. **Bash POSIX mode as a test**: not a dialect check (accepts arrays, `[[`).
