## Summary

- **POSIX.1-2024 (Issue 8) made formerly "bash-only" features standard**: `set -o pipefail`, dollar-single-quotes `$'...'`, `read -d delim`, `find -print0`, `xargs -0` and `xargs -r`, `realpath [-E|-e]`, `readlink [-n]`, `timeout`, and `test -ef/-nt/-ot`. It still does NOT standardize `mktemp`, `stat`, `sed -i`, `grep -r`, `echo -e`, `local`, `[[ ]]`, arrays, `${x//a/b}` or `${x:0:1}` (text read from the 2024 edition; spot-checked by grepping each utility page).
- **Implementations ship the new features unevenly** (MEASURED across 11 shells): dash 0.5.12 lacks `pipefail`, `$'...'` and `read -d`; busybox ash 1.35/1.37, mksh R59c, both ksh93u+m builds, bash 3.2 and 5.2, and zsh already had all three; yash 2.52 lacks `pipefail` and `$'`; posh 0.14.1 lacks all three.
- **A shell's version number does not tell you its features.** Debian backported `pipefail` into dash `0.5.12-7` (2024-05-17), so Debian 13's "0.5.12-12" accepts it while Ubuntu 24.04's "0.5.12-6ubuntu5" rejects it with `Illegal option -o pipefail` (MEASURED). Upstream dash 0.5.13 (2025-09-21) is the first release with `$'...'`. Probe at runtime, never by `--version`.
- **Lint lags the standard**: ShellCheck 0.11.0 (2025-08-03) still emits SC3040 (pipefail), SC3003 (`$'..'`) and SC3045 (`read -d`) under `#!/bin/sh` (MEASURED); the unreleased git tree turns SC3040 into a POSIX.1-2024-aware check and deletes SC3003. GitHub's `ubuntu-24.04` image carries ShellCheck 0.9.0, Debian 13 carries 0.10.0, Ubuntu 26.04 carries 0.11.0.
- **Bash 5.2 changed two defaults silently**: `patsub_replacement` is on (so `${y/b/[&]}` gives `a[b]c`, not `a[&]c`) and `globskipdots` is on (so `.*` no longer matches `.` and `..`) — MEASURED 3.2 → 5.3. Bash 5.3 (released 2025-07-05) adds `${ cmd; }` and `${| cmd; }`, `GLOBSORT`, `source -p PATH`, `trap -P`, `BASH_MONOSECONDS`, `read -E`, and treats a NULL `$PATH` as `.`.
- **Bash 5.3 is still a minority floor in late 2026**: Arch 5.3.20, Ubuntu 26.04 5.3-2ubuntu1 and GitHub's windows-2025 image (5.3.15) have it; Debian 13 has 5.2.37, AlmaLinux 10 has 5.2.26, Amazon Linux 2023 has 5.2.15 (MEASURED). macOS stays at bash 3.2.57 (GitHub's macOS 26.6.2 image prints it; read-only for real hardware).
- **GitHub `ubuntu-latest` moves to Ubuntu 26.04** (rollout starts 2026-10-19, done by 2026-11-19): bash 5.3.9, dash 0.5.12-12ubuntu3 (has `pipefail`), Rust uutils `coreutils` as `date`/`ls`/`sort` (MEASURED in `ubuntu:26.04`), ShellCheck 0.11.0, PowerShell 7.6.6.
- **uutils is not a flag-for-flag GNU drop-in**: same script, same environment, different output. MEASURED: `LC_ALL=en_US.UTF-8 sort` with the locale not installed gives `A B a b` on GNU 9.4 but `a A b B` on uutils 0.10.0; error messages are re-worded (`error: unexpected argument '-y' found` vs `invalid option -- 'y'`); `ls --version` identifies itself as `uutils coreutils`. GNU `sed`, `grep`, `findutils`, `diffutils` stay GNU on 26.04.
- **fish 4.0 (2025-02-27, Rust port) → 4.9.3 (2026-09-08)** shipped more than 25 tagged releases in 18 months. Breaking items for stored or emitted code: `?` no longer globs (`qmark-noglob`), `{ cmd }` is a compound command from 4.1 (not brace expansion), `bind -k` removed (4.1), fish assumes UTF-8 (4.2), colors/key-bindings become globals with `conf.d/fish_frozen_*.fish` migration (4.3), terminfo dropped (4.5). Distros split: Debian 12 fish 3.6.0, Debian 13 4.0.2, Ubuntu 26.04 4.2.1.
- **nushell churn is real and parse-time fatal**: 0.100.0 (2024-11-13) → 0.116.1 (2026-10-04), no 1.0 date. MEASURED breakage between 0.105.1 and 0.116.0: `$nu.home-path`/`$nu.temp-path` are hard errors (renamed `home-dir`/`temp-dir` in 0.110), `str upcase` warns (deprecated 0.114, `str uppercase` unknown to 0.105 and aborts the whole script at parse time), `find` is case-sensitive (0.107), `each` passes `null` through (0.107), implicit submodule import is gone (0.114), `try ... finally` appeared (0.111).
- **elvish is stagnant**: 0.21.0 (2024-08-14) is still the latest tag in October 2026; `0.22.0-release-notes.md` is a draft on master. 0.20/0.21 removed `except`, `float64`, `eawk`, legacy `a=b cmd` temporary assignment and the `~/.elvish` directory.
- **PowerShell lifecycle is about to turn**: 7.6.6 is LTS (GA 2026-03-18, EOS 2028-11-14, .NET 10); 7.4 LTS and 7.5 both reach end of support 2026-11-10; 7.7-preview.3 is current preview. Windows PowerShell 5.1 (measured 5.1.26100.9444) remains the inbox shell; the 2.0 engine is removed from Windows 11 24H2 (Aug 2025) and Server 2025 (Sep 2025).
- **PowerShell 5.1 vs 7 gaps are measurable**: no ternary, `&&`, `??`, `ForEach-Object -Parallel`, `ConvertFrom-Json -AsHashtable`, `Test-Json`, `$IsWindows`, `$PSNativeCommandUseErrorActionPreference`; `Out-File` writes UTF-16LE with BOM and the console code page is IBM437 (MEASURED). `$PSNativeCommandUseErrorActionPreference` is mainstream since 7.4 but defaults `$false`; `ConvertTo-Json` serializes BigInteger as a number from 7.5 (7.4: object).
- **Test and lint tooling moved**: bats-core 1.14.0 (2026-07-21) makes `run` honour `set -e` and fails an empty suite; Pester 6.0.0 (2026-07-07, 6.2.0 on 2026-09-09) adds `Should-*` assertions and drops PowerShell < 5.1/7.4; PSScriptAnalyzer 1.25.0 (2026-03-20) adds `UseConsistentParametersKind`, `AvoidReservedWordsAsFunctionNames`, `UseConsistentParameterSetName`, `UseSingleValueFromPipelineParameter`; shfmt 3.13.0 (2026-03-09) parses zsh, 3.14.1 (2026-09-06) is current.
- **Smaller shells moved too**: zsh 5.9.1 (2026-05-31) and 5.9.2 (2026-07-12) exist, 5.10 is still unreleased (master NEWS has `${ ... }` funsubs, refined `ERR_EXIT`); yash 2.59 (2025-05-13) is the POSIX.1-2024 push (`read -d`, glob never returns `.`/`..`); busybox 1.38.0 (unstable, 2026-05-13) gives ash `<<<`; ksh93u+m's latest tag is still 1.0.10; mksh's latest is R59c; Oils is at 0.38.0 (2026-09-17).
- **Boring failure modes are measurable and still bite** (MEASURED across 11 POSIX shells): a CRLF script runs lines before it dies with a syntax error (partial side effects, exit 1-3); a UTF-8 BOM makes line 1 "not found" but the rest runs (exit 0) everywhere except yash, which refuses the file.

## Survey

### 1. Bash 5.2 and 5.3 — NEWS and COMPAT in the 5.3 tarball

Read `NEWS` and `COMPAT` from [bash-5.3.tar.gz](https://ftp.gnu.org/gnu/bash/bash-5.3.tar.gz) (the Savannah cgit raw URL and the GitHub mirror both failed from this host). Release date 2025-07-05 from Chet Ramey's announcement as archived at [LWN](https://lwn.net/Articles/1029079). Upstream patch listing at [ftp.gnu.org/gnu/bash/bash-5.3-patches/](https://ftp.gnu.org/gnu/bash/bash-5.3-patches/) showed `bash53-001` … `bash53-010` (last 2026-06-02); the Docker `bash:5.3` image reports `5.3.20(1)-release`, so the listing was probably truncated — treat patch count as unverified.

5.2 items that change behaviour of existing scripts: `patsub_replacement` (item x: `&` in a replacement string is replaced by the match; default on), `globskipdots` (item aa: on by default, `.`/`..` never returned unless explicitly matched), `assoc_expand_once` generalized to `array_expand_once` (items h, k, l, m), `unset arr[@]`/`unset arr[*]` semantics, `varredir_close` option, `$0` set to script name in startup files, `command -p` no longer consults the hash table, new `@k` transform, `%Q` printf format, invalid parameter transformations become fatal in non-interactive shells (item w).

5.3 items (NEWS items): `${ command; }` and `${|command;}` non-forking command substitution (s); `GLOBSORT` variable with `name|size|blocks|mtime|atime|ctime|numeric|none` ascending/descending (q); `source -p PATH` / `. -p PATH` (kk); `trap -P` (j); `BASH_MONOSECONDS` (w); `BASH_TRAPSIG` (x); `read -E` (cc); `compgen -V var` (r); `printf` `%#q`/`%#Q` force single quoting (l); `array_expand_once` shopt replacing `assoc_expand_once` (t); `patsub_replacement` configurable at build time (n); NULL `$PATH` now equals `.` (p, security-relevant); `bash_source_fullpath` shopt (pp); posix-mode job notification and `wait -n` changes (mm, nn, oo, qq); `exit` in a trap without an argument uses `$?` from before the trap only at the trap's top level, "Posix interp 1602" (uu); `MULTIPLE_COPROCS` default on (ff); loadable builtins `kv`, `strptime`, `fltexpr` (p, vv).

`COMPAT` documents `compat52` (test builtin historical algorithm for 5+ primaries; `bind -p/-P` arguments; job notifications while sourcing) and the 5.2 `unset`/`array_expand_once` incompatibilities (items 65-67).

MEASURED (`matrix.sh bash`, 3.2 … 5.3, `fixtures/shifts/probe-bash.sh`): `${ echo hi; }` works only on 5.3 (older versions print a syntax error naming the script path); `${y/b/[&]}` → `a[&]c` on ≤5.1 and `a[b]c` on 5.2/5.3; `.*` expands to `. .. .h` on ≤5.1 and `.h` on 5.2+; `GLOBSORT=size; echo *` re-orders only on 5.3; `EPOCHREALTIME` exists from 5.0, `SRANDOM` from 5.1, `BASH_MONOSECONDS` only 5.3; bash 3.2 fails on `declare -A`, `mapfile`, `${v^^}`, `[[ -v v ]]`, `${a[-1]}`, `printf '%(%Y)T'`, `local -n`, `wait -n`, `shopt -s inherit_errexit`, `shopt -s lastpipe`, `|&`; bash 4.0 additionally lacks `[[ -v ]]`, negative subscripts, `printf %()T`, `lastpipe`; `${A[@]@k}` prints only the value on 4.0/4.2 and `k v` on 5.2+ (silent wrong answer, no error).

### 2. POSIX.1-2024 (Issue 8) — shell command language and utilities

Read the 2024 edition of [Shell Command Language](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/V3_chap02.html) and the utility pages for [read](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/read.html), [xargs](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/xargs.html), [find](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/find.html), [realpath](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/realpath.html), [readlink](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/readlink.html), [timeout](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/timeout.html), [test](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/test.html), [sed](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/sed.html), [grep](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/grep.html). `mktemp` and `stat` pages return HTTP 404 (not in the standard).

Present in 2024: `pipefail` option with the exit-status table, evaluated "at the time it begins execution of the pipeline" (so `cmd | set -o pipefail` has no effect on that pipeline); section 2.2.4 "Dollar-Single-Quotes"; `read [-r] [-d delim] var...`; `find ... -print0` ("followed by a null byte"); `xargs [-prtx] [-E eofstr|-0]`; `realpath [-E|-e] file`; `readlink [-n] file`; `timeout [-fp] [-k time] [-s signal_name] duration utility`; `test` with `-ef`, `-nt`, `-ot`. Absent: `sed -i` (synopsis is `sed [-En] ...`), `grep -r` (synopsis `[-E|-F] [-c|-l|-q] [-insvx]`), `echo -e`, `local` (the word appears only in the list of names the shell reserves for extensions), `test -v`.

### 6. zsh — NEWS (master) and the News page

### 8. fish — CHANGELOG.rst

Read [CHANGELOG.rst](https://raw.githubusercontent.com/fish-shell/fish-shell/master/CHANGELOG.rst) in full for "Deprecations and removed features", "Notable backwards-incompatible changes" and "Scripting improvements". Releases: 4.0.0 2025-02-27 (C++ → Rust), 4.0.1 2025-03-12, 4.0.2 2025-04-20, 4.1.0 2025-09-27, 4.2.0 2025-11-10, 4.3.0 2025-12-28, 4.4.0 2026-02-03, 4.5.0 2026-02-17, 4.6.0 2026-03-28, 4.7.0 2026-05-05, 4.8.0 2026-06-24, 4.9.0 2026-09-03, 4.9.3 2026-09-08. Breaking or silently different for old fish text: 4.0.0 — `qmark-noglob` default (`?` no longer a glob; opt out `set -Ua fish_features no-qmark-noglob`), variables in command position that expand to a subcommand keyword forbidden, `ctrl-c` calls `clear-commandline`, new `bind` key notation (`bind ctrl-x,alt-c ...`), `for` loops no longer remember locals, `foo & && bar` is a syntax error, `source` without filename errors, feature flags `remove-percent-self` and `test-require-arg` (the latter makes `test -n` with no argument false; "we are breaking with POSIX explicitly"), no longer searches Windows `$PATH` entries under WSL. 4.1.0 — `{ echo 1; echo 2 }` compound commands and `{echo,echo}` / `{ echo, echo }` no longer brace expansion, `bind -k` terminfo key names removed, fish no longer reads terminfo (`ignore-terminfo`), `set_color ff0000` emits 24-bit regardless of `COLORTERM`, requires Primary Device Attribute reply from terminal (`no-query-term` to revert), `argparse` overhaul. 4.2.0 — fish assumes UTF-8 even without a UTF-8 locale. 4.3.0 — `fish_color_*`, `fish_pager_color_*`, `fish_key_bindings` default to globals, one-time migration writes `~/.config/fish/conf.d/fish_frozen_theme.fish` and `fish_frozen_key_bindings.fish`. 4.5.0 — terminfo database no longer read at all. 4.6.0 — emoji width default 2 (`$fish_emoji_width`). 4.7.0 — default theme not set in non-interactive shells. 4.8.0 — no `__fish_initialized` universal variable; `cd -L/-P`; files no longer installed under `share/fish/{completions,functions}`. 4.9.0 — `status=123 echo $status` now errors instead of ignoring the override; nested list indexing `$foo[$bar[1] 2]`.

### 9. nushell — release blog posts 0.100 → 0.116.1

## Contested

- **Is `pipefail` safe to assume in `sh`?** POSIX.1-2024 says yes; dash 0.5.12 upstream and Ubuntu 24.04 say no; Debian 12 no, Debian 13 and Ubuntu 26.04 yes; ShellCheck 0.11.0 still warns (SC3040), git master stops. Trending to yes within ~2 years as distros pick up dash 0.5.13+; until then probe, do not assume (see candidates 2-3).
- **Bash floor for portable scripts: 3.2 vs 4+ vs "pin your own bash".** macOS still ships 3.2.57 (runner image evidence), RHEL-family and Debian sit on 5.1-5.2, Arch/Ubuntu 26.04 on 5.3. The sources do not converge; the frame's Q1 default (3.2 if macOS-reachable, 5.x only where the interpreter is pinned) survives. Trending toward "install a modern bash or write POSIX".
- **uutils as drop-in.** Ubuntu's release notes: "not necessarily fully compatible yet… old utilities by the side". Measured: 52 of 55 behaviours identical, the three differences are exactly the ones scripts trip on (collation, error text, banner). Trending toward more compatibility but with a long tail; scripts should not parse tool stderr.
- **`local` in POSIX sh.** Not in POSIX.1-2024; supported by dash, busybox, mksh, bash, posh, yash, zsh (MEASURED); absent in ksh93u+m (which uses `typeset`). ShellCheck SC3043 flags it. Practical consensus: allowed when the target set excludes ksh93.
- **nushell stability.** The project's 2023 road-to-1.0 post promised stabilisation; the 2024-2026 releases keep making breaking changes monthly (hook order, renamed fields, module import rules, type-system tightening) with no 2026 1.0 date found. Trending to continued churn: treat generated nu code as version-pinned.
- **Elvish: alive or dormant?** Last tag 2024-08-14; a 0.22 draft sits on master (last exemplar commit 2025-07-14). Trending dormant-but-maintained; do not expect new syntax.
- **fish distro lag vs upstream pace.** Upstream ships near-monthly 4.x releases with removals (terminfo, `bind -k`); Debian 13 is on 4.0.2 and Debian 12 on 3.6.0. Emitted code must run on both 3.6 and 4.9 for now; trending to 4.x-only after Debian 12 EOL (2028-06-30 per Microsoft's Debian table).
- **Pester 5 vs 6, PowerShell 7.4/7.5/7.6.** Pester 6 requires 5.1/7.4+ and removes commands; PowerShell 7.4/7.5 EOS 2026-11-10. Trending to 7.6 + Pester 6 within months; Windows PowerShell 5.1 remains the inbox floor.
- **Debian 13 shell packages.** The frame claimed Debian 13 drops yash and posh; MEASURED here: yash has no candidate but posh 0.14.1 is present.
