# UX for developer tools: landscape scout

Scope: tools whose user is an engineer (CLIs, TUIs, APIs, SDKs, config files, agent-facing tools). Goal: list the questions an expert must settle, ranked for the OCX and Grimoire fleet (Rust CLIs `ocx` and `grim`, plus Astro/MkDocs sites and one Vite GUI). Exit-code and stream contracts per language are already covered by the language sets and are marked yes or partial.

## Method and limits

20 pages were opened and read (listed in the sources table). WebSearch snippets were used only to find pages and are flagged "search-derived, page not opened" wherever they carry a claim. Several pages failed to open (HTTP 403/404/429, or the domain safety check was rate-limited) and the web-search budget ran out mid-run. Not read, so no claim rests on them: the 12 Factor CLI essay, the GNU Coding Standards pages, Elm's "Compiler Errors for Humans", the SPACE paper, the DevEx ACM Queue paper, the DX Core 4 whitepaper, Stripe's error docs, Node and Python color docs, and the Charm/Ratatui design material beyond the two pages named below. The fleet measurements were run locally with the commands shown.

## Fleet measurements

All run 2026-11-27 from `/tmp` with the installed binaries (`ocx` 0.6.8, `grim 0.16.0`).

| Command | Result | Reading |
|---|---|---|
| `bash -c 'ocx --version; echo $?'` | `error: unexpected argument '--version' found`, exit 64 | The GNU and POSIX-adjacent convention of `--version` is absent from `ocx`; version lives in `ocx about`. `-V` also fails. |
| `bash -c 'grim --version'` | prints `grim 0.16.0`, exit 0 | `grim` follows the convention. The two sibling CLIs disagree. |
| `bash -c 'ocx about --json'` | `error: unexpected argument '--json' found`, exit 64 | Flag works only before the subcommand. |
| `bash -c 'ocx --json about \| head -3'` | JSON with `"schema_version": 1` | Machine output exists and is versioned. `ocx --help` says `--format` "applies to every command", yet position matters. |
| `bash -c 'grim nosuchcmd'` | `unrecognized subcommand`, `tip: a similar subcommand exists: 'schema'`, exit 64 | Typo suggestion present. clig.dev says suggest and ask, not run. |
| `bash -c 'ocx nosuchcmd'` | names the plugin install route, exit 64, one stderr line | Good recovery text. |
| `bash -c 'ocx >/dev/null 2>&1; echo $?; grim >/dev/null 2>&1; echo $?'` | 0 and 0 | No-argument invocation prints help and exits 0. |
| `bash -c 'ocx --help \| wc -l; grim --help \| wc -l'` | 126 and 83 lines | Full help is long; no short-help tier. |
| `bash -c 'grim --help \| grep -iE "color\|format\|no-input"'` | `--color <auto\|always\|never>` honoring `NO_COLOR` / `CLICOLOR*` / `TERM=dumb`; `--format json`; progress mode `auto\|json\|none` | Agent-facing progress (NDJSON on stderr) already exists. No `--no-input` flag shows. |
