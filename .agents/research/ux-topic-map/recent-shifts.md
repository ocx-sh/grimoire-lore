# UX recent shifts (2024-11 to 2026-11)

Scope: what changed in interface design and its platform in the last 24 months, and which older advice each change retires. This is a scout artifact: it lists the questions an expert must be able to answer, not the answers. Every platform fact below was fetched on 2026-11-27 (no memory facts). Pages whose body could not be read are named in "Gaps" and are not used as sources.

Method notes. Web search snippets were not used as sources; each URL cited was opened with WebFetch, or read with curl. The web-features Baseline data was downloaded and queried locally (commands in "Measurements"). The WebSearch budget ran out mid-run, so v0, Apple Human Interface Guidelines, NN/g generative-UI material and APCA status are thinner than the rest (see Gaps).
