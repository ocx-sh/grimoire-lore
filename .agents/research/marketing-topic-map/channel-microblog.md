# Short-text social channels for software: topic map

Scope: X, Bluesky, Mastodon and the fediverse, Threads, as channels for announcing and supporting software. Written for agents that draft or schedule posts without a human in the loop, for open-source developer tools first.

## How this was researched, and what could not be

- Platform facts come from platform-owned sources fetched on 2026-11-27: X developer docs and changelog, Bluesky lexicons and docs source, Mastodon docs source and changelog, Threads developer docs. Where a doc page and the machine-readable schema disagree, the schema is treated as authoritative and the gap is recorded (Bluesky image size, below).
- Open-sourced ranking code was cloned and read: `xai-org/x-algorithm` (commit date 2026-11-25, `param.rs` mirror sync 2026-11-24). Weights below are quoted from that file.
- Two fetch limits shaped coverage. The session web-search budget was exhausted, so no discovery search ran; every source is a URL opened directly. The WebFetch safety check was rate-limited for several minutes at the start. Consequence: no source was found for developer audience share on X versus Bluesky in late 2026, for launch-thread anatomy on X, or for thread versus single-post effect on any of the four platforms. These are listed as open candidates, not answered. X help-center pages (`help.x.com`) returned HTTP 403, so the X automation page was reached only through the developer policy.
- Vendor studies (Buffer) are observational and sell scheduling tools. They are cited with that caveat.
- Wikipedia is used only for user-count figures and is labelled secondary.

## Contested

1. **Do external links reduce reach on X?**
   - Yes: Buffer's 18.8 million post analysis shows link posts at about 0% engagement for non-Premium accounts after March 2025 and advises leading with native content or moving links to replies. https://buffer.com/resources/links-on-x/ . The API now charges $0.20 for a post with a URL against $0.015 without, which shows the platform treats link posts as a distinct, costly class. https://docs.x.com/changelog
   - Not shown by the platform's code: the open ranking repository lists "link" clicks as a predicted positive action (weight 0.2) and contains no link penalty in the files read. https://github.com/xai-org/x-algorithm . Counter-point: `has_url` is sent as a content feature to the re-ranker service, which is not in the repository, so the code neither proves nor excludes a penalty. Buffer itself calls its explanation "most likely", not confirmed, and the study is observational. I found no X statement on the point (X posts could not be fetched).
2. **Does X Premium raise reach?** Buffer reports about 10x. https://buffer.com/resources/twitter-timeline-algorithm/ . I found no Premium or verified term in `param.rs`, the scorers or the value model, so the open code does not show the boost; the closed re-ranker or candidate sourcing could. The API docs do tie media limits to Premium status. https://docs.x.com/changelog
3. **How much more is a reply worth than a like?** Buffer's X algorithm article (published 2026-02-24) states "A reply is worth 27x more than a like, and a conversation (reply + author reply) is worth 150x more than a like" ( https://buffer.com/resources/twitter-timeline-algorithm/ ). It links the figure to OpenTweet's post (published 2026-02-25, https://opentweet.io/blog/how-twitter-x-algorithm-works-2026 ), which calls them "approximate multipliers" "based on the open-sourced ranking model and 2026 observations" and cites no source or derivation. The repository weights give reply 5.0 against favorite 0.708 (about 7x), and the README states weights multiply each viewer's predicted probability, so ratios cannot be read as count equivalences. https://github.com/xai-org/x-algorithm . Treat the 27x and 150x figures as unsupported.
4. **Is Bluesky growing or fading as a channel?** Total registered users rose to over 47 million by 2026-10-14, https://en.wikipedia.org/wiki/Bluesky , while the same article reports daily users falling from about 2.5 million (March 2025) to about 1.5 million (September 2025) and daily posters falling each month since January 2025. Both can be true; registered accounts are not an audience. Bluesky's own posts give only registered counts. https://bsky.social/about/blog/03-19-2026-series-b
5. **Is the posting-time advice stable across platforms?** Buffer's X article says weekday mornings, 9 a.m. Tuesday; its Bluesky study says Saturday 17:00 and weekday evenings. Neither states a date range and both come from the same vendor's customer posts. https://buffer.com/resources/twitter-timeline-algorithm/ ; https://buffer.com/resources/best-time-to-post-on-bluesky/
6. **Does EU AI Act Article 50 apply to a brand account's AI-drafted posts from 2026-08-02?** The Act's page states the date and the human-review exception, and also notes an amendment through a Digital Omnibus that I could not read. https://artificialintelligenceact.eu/article/50/ . The exception turns on "editorial responsibility", which is a legal judgement for a legal scout.
7. **Bluesky image limit.** The docs prose says 1,000,000 bytes; the schema says 2,000,000 bytes, "formerly limited to 1 MB". Schema treated as authoritative. https://raw.githubusercontent.com/bluesky-social/bsky-docs/main/docs/advanced-guides/posts.md ; atproto lexicon (clone, 2026-11-27).
