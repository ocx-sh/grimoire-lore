Reading of the fleet: changelogs are generated by git-cliff from conventional
commits, using the Keep a Changelog preset, with `**BREAKING**` as an inline
suffix and the scope in italics. Entries are commit subjects (for example
"Cascade repair points every alias a build owns at the build tag's own index
*(cascade)*"). No fleet repository sends email, so the email half of this corpus
is for the "then any team" audience; the changelog half is the first-adopter
core.
