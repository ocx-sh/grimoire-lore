# GitHub as a channel — landscape scout

Method note. Every fact below was fetched on 2026-11-27 from the URL beside it. GitHub Docs pages carry no publication date; the "date" for those is the fetch date. Web search was unavailable (the shared search budget was exhausted), so two corpus areas are thin: maintainers' "first thousand users" accounts and awesome-list/trending reverse-engineering studies. They are listed as gaps, not guessed. Nothing here is from memory. Measurement commands: none run; this scout measured no repository. Where a candidate needs a measurement, the "check" column names the command a later worker should run.
