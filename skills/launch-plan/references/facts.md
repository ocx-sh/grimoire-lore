# Launch venue facts

Every venue gate, rule, window and measured list state the launch plan uses sits in this file and nowhere else. Cite a row by its id, in square brackets, such as `[LP-F03]`. A row is the starting value. On plan day, re-fetch the venue page and write the fetched figure in the plan's `## Venue facts` section (CH-LAUNCH-13).

## Dates and versions

- Fetched and verified: 2026-11-27. Every `verified` date is the date the page was read. Product Hunt help pages show only "Updated over 3 weeks ago", so their age is recorded as `relative:<text>@<fetch date>`. Hacker News, Console.dev, Changelog News, DEV, directory pages and contributing files show no date, so their `source_date` is `none`.
- Refresh cadence: every row here carries `refresh_days` 30, the floor for this skill, because venue rules and list states move. The checker `facts_check.py` in `channel-publishing` fails on the first row past `verified + refresh_days`. Re-fetch the page; never extend the date.
- Every `producthunt.com` row is a manual row. The host bars scripted access, so no scheduled job fetches it. A human re-reads the page, compares it with `expect`, and edits `value` and `verified`. The `expect` text of rows LP-F04, LP-F05, LP-F06, LP-F07, LP-F09, LP-F10 and LP-F11 comes from a paraphrase of the page, not from a verbatim quote. The first human re-read confirms or corrects it.
- Re-check events: a Product Hunt change to its leaderboard wording (its ranking wording was unsettled when read), a new Console.dev lane, a change to a list's contributing file, and every plan day.
- Provenance: `platform` is the venue's own page or contributing file, `vendor` is a rival's page or API measurement. A `vendor` row is a claim, never a limit and never a threshold (CH-CORE-15). Rows LP-F28, LP-F29 and LP-F34 to LP-F47 carry no threshold that a check enforces.
- Rows LP-F43 to LP-F47 are measurements made through the public GitHub API on 2026-11-27, with 2026-08-29 as the 90-day start. They are a dated example of CH-LAUNCH-17, never a standing exclusion list. Re-run CH-LAUNCH-17 on every plan.
